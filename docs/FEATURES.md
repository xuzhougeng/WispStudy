# 功能详解

## 新手引导

第一次打开（书架上还没有文献库时），窗口里会有一张小卡片一步一步带着走，共六步。卡片站在这一步要点的东西旁边，那样东西外面有一圈强调色的线；页面不变暗、不锁住，每一步都是在自己的文献库里真的做一遍。

1. **先建一个文献库**：指着首页的「新建文献库」。
2. **往里放几篇文献**：指着新文献库的几种开始方式（或侧栏的「添加文献」）：拖入 PDF、粘贴 DOI / PMID、从 Zotero 导入，或者让助手检索。
3. **点开一篇**：指着列表的第一行。
4. **读它，问它**：指着文献的「信息 / PDF / 提问」三个标签。
5. **向整个文献库提问**：指着侧栏的「助手」；还没配置模型时，卡片上多一句说明和「配置模型」。
6. **写综述时，顺着往下走**：指着侧栏的「检索与导入、筛选、提取、写作」；卡片上有「图文教程」，打开项目主页上的教程。

前三步没有「下一步」：做完了（建好了库、库里有了文献、点开了一篇），引导自己往下走；后三步只是指给你看，点「下一步」。它显示的总是最早一件还没做的事：中途回了首页，它就回到「打开一个文献库」，再进文献库又接着原来的那一步；要指的东西不在眼前时（比如正在阅读模式里），卡片退到窗口左下角等着。打开对话框、菜单、命令面板或设置时它让开。

卡片右上角的 × 随时结束；走完或结束之后它不会再自己出现，关掉窗口时走到一半的，下次打开接着走。想再看一遍：「设置 › 关于」里的「新手引导」，或命令面板里搜「新手引导」。已经有文献库的人升级之后不会被它打扰。

## 多个独立的文献库

启动后的首页是文献库列表。每个文献库有自己的名称、主题描述和标识色，是数据目录下的一个独立文件夹（数据库、PDF、自定义词条都在里面），可以单独备份或拷走。首页的文献库按建立的先后排列，打开一个不会改变顺序；把一张卡片拖到另一张上，它就换到那个位置，这个顺序会记住。文献库多了，右上角的两个图标可以把卡片换成列表：一行一个文献库，名称、主题、篇数和上次打开的日期各成一列，点击、右键菜单和拖动排序都和卡片一样；选了哪一种会记住。

几个文献库可以同时干活。助手在一个文献库里批量筛选、提取词条、查找开放全文或翻译时，回首页或打开另一个文献库都不会打断它：那个文献库在后台接着做，结果照常存进它自己的库里，各库之间互不影响。首页上它的卡片（或列表里那一行）写着在做什么、做到第几篇，如「筛选 12 / 80」；在别的文献库里，侧栏底部也有它的一条进度，点一下就回到那个文献库，要停就在那里停。做完时窗口上方提示一句，如「『根毛发育』的筛选做完了：80 篇，其中 3 篇没有成」。助手的回答也是这样：离开时还在回答的对话接着答，需要你同意才能继续的步骤（例如导入）会等你回来，卡片上写着「等你同意」。导入 PDF、Zotero 迁移、文字识别和朗读还不会在后台继续，离开文献库就停。退出应用会结束所有后台任务，已经得到的结果都保留。

## 先聊，后建库：首页的助手

不必先建文献库。首页右下角的圆按钮是助手：点开是对话页，上面是输入框，下面是「最近对话」。输入框上方有一行字，每次打开换一句（「今天想弄清楚哪个问题？」「哪两篇文献值得放在一起比一比？」……），只是个开头，不必照着它问。说一个想法（「帮我调研一下……」），或者点输入框左边的加号、把 Word 稿件（.docx）或几个 PDF 拖到首页（会打开对话页、文件放进输入框；拖到对话页上的 PDF 也是这样），再发出第一个问题。输入框下面的「调研一个想法」「审一份稿件」「找几篇文献」「从 Word 建文献库」只往框里放一句开头（审稿件和从 Word 建文献库会先让你选文件），不会自己发出去。左上角「← 首页」或 Esc 回到首页，没发出去的字和文件留着。

- 发出第一个问题时才会建立这次对话；只是打开首页或打字，不会在磁盘上留下任何东西。对话按第一个问题命名，右键可以重命名。
- 对话页只有这次对话：没有侧栏和文献库的导航，左上角「← 首页」回去；上方的「历史」列出其他对话，「新对话」回到空的对话页。助手知道还没有文献库，需要文献时自己到 PubMed、Europe PMC、Crossref、arXiv 检索；值得留下的文献它会用检索式导入（导入前先问你），上方「文献 N」列出这次对话收进的文献。
- 跨文献库提问：首页的助手读得到书架上所有的文献库。直接说「在我的文献库里找……」「比较一下『A』和『B』两个库里关于……的研究」，或点输入框下面的「问我的文献库」；点名某个库就只查那个库。它会到各个库里列文献、检索全文、读原文，回答里的每条依据带着标签，回答下面的出处写明来自哪个库，如「P7（根毛发育）· 题目」，点一下就打开那个文献库里的那篇文献和那一页；这次对话在首页「最近对话」里还找得到。别的文献库在这里只读：要加标签、改状态或导入文献，请打开那个库再做。在文献库里面的「助手」仍然只管自己这个库。
- 拖进来的 Word 文件是要审的稿件，显示在对话右边，窗口够宽时再右边是批注栏。助手把意见作为批注留在稿件对应的原文上（只在原文里找得到的才留下），改不改由你逐条决定；稿件上方的「导出」可以得到带批注的 Word 文件。拖进来的 PDF 成为这次对话的一篇文献。
- 「从 Word 建文献库」：选一份写好的 Word 稿件，发出后助手读出它参考文献表里的每一条（带 Zotero / Mendeley 引用域的直接取域里的文献信息，否则按「参考文献」「References」后面的条目逐条读），征得你同意后收进这次对话：有 DOI 的按 DOI 到 Crossref 核对，没有 DOI 的按条目文字到 Crossref 查（题目、年份都对得上才采用）补上 DOI 和期刊信息。读不出来的条目不会凭空补写，助手会逐条告诉你；只按文字读出、没能核对的也会提醒你核对。对话以「<文件名> 的参考文献」命名，Word 文件不会被改动，也不会作为待审的稿件显示；收完后对话下面会出一张卡片，提醒首页上还没有它，点卡片上或对话上方的「建成文献库」就是一个文献库；「稍后」先收起卡片，再收进文献时会再出现。助手也会在一件事做完、下一步该由你决定时，在回答下面放一张这样的卡片：按钮只有几种（替你说一句话、建成文献库、查找开放全文、打开筛选或写作等页面），按下才执行，右边的 × 收起。同一件事在文献库的助手里也能做：附上 Word 文件，说把参考文献收进来。
- 「最近对话」按时间列出这些对话：标题、收进的文献数（有时才写）和日期。右键可以重命名、建成文献库或删除；删除和移除文献库一样，只是把文件夹移到数据目录的 removed 下。
- 聊出眉目后点对话上方的「建成文献库」：在新建文献库的对话框里填名称、主题和标识色，名称旁的星形图标可以让模型按这次对话拟名称和主题。确认后窗口就地变成这个文献库，侧栏出现，对话接着进行；收进的文献就是文献库的文献，什么都不用搬。
- 这些对话不在 `wisp list_libraries` 和 MCP 的文献库列表里，也不算在「只有一个文献库时可以省略」之内；用它的 ID 指定时仍然可以访问。旧版本的 Wisp Study 打开同一个数据目录时，会把这些对话当作普通文献库列出。

要把一个文献库交给另一台电脑上的 Wisp Study，在首页文献库卡片的菜单里选「导出文献库」，或在文献库里点「导出」，选「整个文献库」。可以选含 PDF 或不含 PDF：不含时文件小得多，对方拿到文献、词条、筛选、笔记、对话、稿件和图片库，但没有全文，PDF 上的标注和已读出的全文也不带过去。导出的是一个 `.wispstudy` 文件（其实是 tar.gz 压缩包）。对方在首页点「导入文献库」选这个文件，或直接拖进窗口，就会新建一个文献库；同一个文件导入两次会得到两个库，同名的在名称后加编号，不会与已有的库合并。由更新版本导出的文件，需要先升级再导入。改名前的 Wisp Paper 导出的 `.wisppaper` 文件也可以这样导入。

## 收集

- 粘贴 DOI 或 PMID（或它们的链接）：从 Crossref 和 Europe PMC 查询题目、作者、期刊、卷、期、页码、年份、摘要。可以一次粘贴多个，一行一个或用空格分开：多个时对话框随即关上，在后台查询，进度和每一个的结果在左侧栏的「按 DOI / PMID 导入」里；已有的文献和认不出的词跳过，不耽误其余的。只粘贴一个时在对话框里等结果，没查到会说明原因。
- 粘贴网址：同一个对话框也认文献网页的网址（出版商的文章页、arXiv 的摘要页）和 PDF 本身的地址，可以和编号混在一起粘贴。网址在后台处理，结果和编号一起列在左侧栏的导入明细里。每个网址只用本机的网络打开一次：在校园网里、出版商按 IP 开放下载的，PDF 也能取到。网页上写着的 DOI 或 PMID 用来查询题目、作者等信息（库里已有的不会重复添加），再下载网页标出的 PDF；PDF 拿不到（付费墙、登录页、验证页、只是补充材料）时再找开放获取的版本。网页打不开、但网址里写着 DOI（如 `…/doi/10.1021/…`）时，照样按这个 DOI 添加。PDF 的地址按拖入的 PDF 处理。最后没有 PDF 的，记录照样保留，明细里写出原因，可以在浏览器里下载后把 PDF 拖进窗口，它会附到这一条上；既认不出编号也没有 PDF 的网址不添加。一个网址最多花两分钟：对方迟迟不回应时不再等下去，后面的网址接着处理；已经添加的文献保留，明细里写「花的时间太长」，缺的 PDF 之后可以用「查找开放全文」再找。不登录，不带 cookie，不冒充浏览器，也不跟随网页上 PDF 以外的链接。
- 拖入或选择 PDF：提取文字，在前两页找 DOI 并查询元数据；找不到 DOI 时以文件名建条目。同一个文件换了名字再拖进来，按文件内容认出是已有的那篇（在回收站里的也算），不会多出一条。
- 没有 DOI 的文献可以「按题目补全」（文献详情里的按钮）：题目取自文献本身，题目还是文件名时取自 PDF 首页（可以改），再到 Crossref、Europe PMC 和 arXiv 查找相近的记录。每个来源单独说明查到几条、没有查到还是没查成。候选列出题目、作者、年份、期刊和编号，标出与所查一致和不一致的地方；预印本和正式发表的版本是两条记录。点一条候选逐个字段核对：默认只勾选现在空着的字段和只是文件名的题目，已有的内容勾选后才替换；题目和所查不一样的记录不预先勾选任何字段。候选已是库里另一篇文献时不能写入。发出去的只有题目、作者和年份，不上传 PDF，不经过模型，也不打开浏览器抓取网页；一篇文献可以一直没有 DOI。
- 有 DOI 或 PMID、但缺期刊等信息的文献可以「按 DOI 补全」（没有 DOI 时是「按 PMID 补全」）：在右键菜单里，期刊、作者或年份空着时文献详情里也有这个按钮。按编号到 Crossref 和 Europe PMC 取这一条记录，同样逐个字段核对，默认只勾选空着的字段，已有的内容勾选后才替换。记录的题目和文献的不一样时（比如 PDF 首页印的是所引文献的 DOI）会提醒，并且不预先勾选任何字段。发出去的只有这个编号。
- 一次导入多个 PDF 时，侧栏下方有一块进度（已完成几个、正在读哪个文件），换到别的页面也看得到。读完后它变成一份汇总，直到你关掉：新增几篇、附到已有文献几篇、在回收站里所以没导入的几篇，以及还要处理的（没认出 DOI、待补全题目和作者的；没读出文字的）。点这一块打开明细，逐个文件列出结果和原因，点一行打开那篇文献。
- 导入 BibTeX / RIS；手动录入。
- 从 Zotero 6 / 7 本地数据库导入个人库与群组库的文献信息、标签、笔记和本地 PDF；分类路径转为标签。数据库里有不止一个文献库（我的文库和群组）时，选好 `zotero.sqlite` 后先选导入哪一个，每个都标着条目数，也可以选「全部」；文献库里有分类时，还可以只勾选其中几个分类（各带条目数，含其子分类）。只读源库、复制附件，已有记录保留并补 PDF；进度和结果明细列出重复、回收站及失败原因。见 [Zotero 导入教程](ZOTERO.md)。
- 按 DOI、PMID、题目去重，重复导入不会产生重复条目。

## 整理

- 搜索（题目、作者、DOI、标签、词条、摘要、笔记）、筛选、排序。
- 全库查找（#273）：搜索框里的词，按 Enter（或点框尾的「查全文与标注」、列表为空时的「在全文和标注里找」、命令面板里的「在全文和标注里找「…」」）就在整个文献库里逐字找：每篇已读出文字的全文和附件、PDF 上的标注（高亮、下划线标出的原文，写在标注、便签、文本框上的话）、笔记、题目和摘要。不分大小写，跨行、行末用连字符断开的词也能找到；中文没有空格，词在一句中间也能找到。结果在列表的位置上按文献分组，每处写明是第几页（附件写 S1、S2）、是哪种标注或笔记，后面是所在的那一句，找到的词标出底色；点一处（或用 ↑↓ 选中后按 Enter）打开那篇的 PDF 跳到那一页，那一句或那处标注被标出，在笔记里的就打开笔记并选中那几个字。查找在后台进行，接着改搜索词，结果会跟着更新。有 PDF 却没有读出文字的文献（扫描件、加密、还没读取的）正文查不到，栏头写着有几篇，悬停说明可以怎么办。按 Esc 或点「返回列表」回到文献列表。查找只读，不改动文献库。
- 按区间筛选（#236）：筛选条上的「年份」除了逐年，还有「近 3 年」「近 5 年」「近 10 年」（按年份算，今年算一年：2026 年的近 3 年是 2024–2026）和「自定义区间…」，填起止年份，只填一头也可以（2020 年起，或 2010 年及以前）。「影响因子」有 ≥ 3、≥ 5、≥ 10、≥ 20 和「自定义范围…」（如 5–10）。「分区」选 1区、1–2区、1–3区（JCR 是 Q1、Q1–Q2、Q1–Q3），菜单下半部分换分区表（中科院 / 新锐 / JCR），和「设置 › 外观 › 期刊分区」是同一个选择，列表的「分区」列跟着换，已设的分区筛选也换成新表里的同样几区。菜单里每一项旁边是整个文献库里符合它的篇数。几项可以同时用，和别的筛选、搜索一起生效，侧栏的数字和列表下方的「显示 N / M 篇」随之更新。影响因子和分区是期刊的：期刊不在随应用附带的期刊表里的文献，以及没有年份的文献，不在对应的筛选结果里。
- 侧栏的数字跟着搜索和筛选走：输入搜索词或设了筛选后，「全部文献」「最近添加」「未读」「收藏」「缺 PDF」旁写的是换到这个视图会显示几篇，每个标签旁写的是当前显示的文献里有几篇带它（为 0 的变淡）；清空搜索和筛选，回到整个文献库的数字。标签的先后不随之变动。
- 侧栏的标签可以多选，也可以排除：点一个标签只看带它的文献，再点一下取消；按住 `⌘`（Windows 上 `Ctrl`）点再加一个标签，列表只留同时带着所有选中标签的文献（和 Zotero 一样），再按住点一下把它去掉；按住 `⌥`（Windows 上 `Alt`）点一个标签是排除它，带它的文献都不显示，这一行的名字划掉、变淡，旁边的数字是它藏起了几篇，再点一下取消排除。右键标签也有「只看这个标签」「同时要有这个标签」「排除此标签」「取消排除」。选了或排除了标签时，「标签」两字右边有「清除」，一下全部取消；「清空筛选」也会取消。选中标签时，每个标签旁的数字是再加上它还剩几篇。
- 文献列表右侧有一条滚动条，表示列表滚到了哪里、一屏是全部的多少；拖动它快速到列表的任何位置，点它上方或下方的空处直接跳到那里。
- 阅读状态、收录判断、收藏、标签、笔记。
- **自定义词条**：每个文献库自己定义字段（文本 / 多值 / 单选），可填写、筛选、作为表格列。
- 「全文」一栏有四种状态：无全文、有链接、已存 PDF，以及「PDF 无文字」（存了 PDF 但没读出文字，全文暂时不能用于提问）。可以按它筛选。
- **影响因子与分区**：列表的「影响因子」「分区」两列，和文献详情里期刊下面的一行（`IF 18.1 · JCR Q1 · 中科院 1区 Top · 新锐 1区 Top`），按期刊名查自应用附带的期刊表：JCR 2025 影响因子与分区、中科院分区表升级版 2025、新锐期刊分区表 2026，以及国际期刊预警名单 2025（在预警名单里的期刊用警示色显示，悬停看原因）。全称和 PubMed 式缩写（`Nat Commun`、`J Biol Chem`）都认得，不联网。「分区」列显示哪一种分区在「设置 › 外观 › 期刊分区」里选；点列名可按影响因子或分区排序。右键列名可以收起这两列。
- 移到文献库：文献右键菜单，或「信息」页那一行按钮末尾「⋯」里的「移到文献库…」，把这篇连同 PDF 和附件、标注、读到的位置、关于它的对话和图片库里从它截的图一起移到另一个文献库。同名同类的自定义词条一起带过去，没有对应词条的会提示；收录状态回到「待判断」，因为是否收录要按新库的主题重新判断。新库里已有这篇（同一 DOI、PMID、题目或同一份文件）时不会多出一条，文件和标注并到已有的那条上。原来的那条留在原库的回收站里，可以恢复；从一段对话里移走、对话里又没问过问题时，这段对话一并删除（移到数据目录的 removed 文件夹）。
- 回收站：删除的文献可恢复（一篇篇恢复，或「全部恢复」），并继续阻止同一篇被重复导入。「清空回收站」把里面的文献连同笔记、词条、标注、PDF 和图片从磁盘上彻底删除，无法恢复，要输入「我已知晓」才会执行；清空之后它们不再阻止重复导入。单篇的「彻底删除」同样是真删除，确认一次即可。移到回收站是后悔药，离开回收站就没有了。
  - 一次处理几篇：点一行选中它，按住 ⌘（Windows 上是 Ctrl）点或点行首的小方框再加一篇、去掉一篇，按住 Shift 点选中一段；⌘A / Ctrl+A 或顶上的「全选」选中全部，Esc 取消。选中之后，顶上的两个按钮换成「彻底删除所选 N 篇」和「恢复所选 N 篇」，右键选中的行也是对它们全部操作，按 Delete 也是彻底删除所选。彻底删除几篇前确认一次，说明有几篇、文件一起删除、无法恢复；选中的是回收站里的全部时，和「清空回收站」一样要输入「我已知晓」。离开回收站再回来，选择就清掉了。
- 导出 BibTeX、CSV（当前列表）。
- **命令面板**：按 `Ctrl` / `⌘` + `K` 打开，输入几个字找到要做的事或要找的文献：切换页面和视图、添加与导入、导出、打开别的文献库、切换外观、打开设置的某一页；输入题目、作者、标签或摘要里的词，直接打开文献库里的那篇文献。上下键选择，回车执行，Esc 关闭；中英文都能搜到命令。
- 用 `Esc` 往回退：一下收起一样（弹出列表、菜单、对话框、选区、阅读模式、文献详情……），都收完了再按一下，回到「所有文献库」，和点左上角「← 所有文献库」一样。正在输入时不会一按就走：第一下先离开输入框，搜索框里的字再按一下清掉；助手的输入框里有没发出的字时留在文献库里。不想要这一步，在「设置 › 快捷键」里移除或换个键。
- 侧边栏：拖动它右侧的分隔线改变宽度，宽度会记住；双击分隔线、点左上角的按钮或按 `Ctrl` / `⌘` + `B` 收起，把窗口让给列表和文献，再点按钮或按快捷键回来。拖到很窄也会收起。

## PDF 预览

在详情面板里直接看 PDF。渲染用纯 Rust 的 [hayro](https://github.com/LaurenzV/hayro)，不依赖系统 PDF 库。

- 当作 PDF 阅读器用：把一个 PDF 拖到首页，或在访达 / 资源管理器里右键 PDF 选「打开方式 › Wisp Study」，直接进入阅读模式。哪个文献库里已有这份文件（按文件内容认，换了名字也算），就在那个库里打开这篇，标注和读到的位置都在；哪里都没有的，成为一段以文件名命名的新对话里的文献，在「最近对话」里找得到，下次再打开同一份文件还回到这里。`Esc` 退出阅读模式就是这段对话，可以就这篇提问，或「建成文献库」留下来，也可以在「信息」里「移到文献库…」放进已有的文献库。PDF 首页上的 DOI 会在后台查询，查到后补全题目、作者等信息，对话也改用论文题目命名。不会把 Wisp Study 设成 PDF 的默认打开方式；Windows 上「打开方式」的这一项由安装包登记，便携版没有。

- 正文与附件：文献详情的文件分成「正文 PDF」和「附件／补充材料」两块，各有自己的添加按钮。每个 PDF 文件行都有「阅读」，附件也能在内置阅读器里打开，缩放、高亮、方框、便签都可以用。阅读器工具栏左侧写着正在读的文件（「正文 · …」或「附件 S1 · …」），点它切换到正文或其他附件；每个文件各自记住读到的位置，换一篇文献、关掉文献库或退出应用再回来，都从上次读到的地方接着读；标注也各归各的文件。分屏时一半可以换成另一个文件：正文在一半，补充材料在另一半，读正文时补图一直留在眼前（见下面的「分屏」）。
- 归入已有文献：补图、补充方法这样的 PDF 如果是单独导入的，会各占一行。在文献列表里右键它（或选中几条一起右键），选「归入已有文献…」，在弹出的列表里按题目、作者、年份找到它所属的文章，点「归入」。它的文件成为那篇文章的附件，在上面做的标注、读到的位置、读出的文字和从它截的图都跟着；原来单独的那一条进回收站。归入后顶上的提示里有「撤销」；过后想拆开，从回收站恢复那一条，文件就回到它名下。
- 在列表里展开：有附件的文章，行首有一个小箭头，默认收起，只占一行。点箭头，下面按文件名列出正文和各个附件（正文在前，附件按 S1、S2 的顺序）；点任意一行直接打开那份文件，PDF 在内置阅读器里打开，右键是这个文件的菜单。在详情里「添加附件」加的文件也列在这里。只有正文的文章没有箭头。
- 就这篇文献提问时，正文和全部 PDF 附件一起交给助手，对话上方列出已纳入的文件。回答引用附件时写成 `[P1 S1 p.2 "…"]`（S1 是第一个附件，页码是附件自己的），出处卡片写明附件编号和文件名；点击会打开那个附件并高亮这句原文。

- 表格列：拖动表头里两列之间的分隔线改变列宽，宽度会记住，双击分隔线恢复这一列的默认宽度。右键表头选择显示哪些列（期刊、年份、全文、阅读、收录和各个自定义词条），也可以一次恢复默认列宽。窗口不够宽时，放不下的列先让出位置，「文献」这一列的表头末尾会出现「+N 列」：鼠标停在上面说是哪几列，点它选择显示哪些列；拉宽窗口或收起侧栏，它们就回来。放不下的题目、期刊和词条以「…」结尾，鼠标停在上面显示完整内容（题目的提示里还有作者、年份、期刊和全部标签）。
- 表格列：拖动表头里两列之间的分隔线改变列宽，宽度会记住，双击分隔线恢复这一列的默认宽度。右键表头选择显示哪些列（期刊、年份、全文、阅读、收录和各个自定义词条），也可以一次恢复默认列宽。放不下的题目、期刊和词条以「…」结尾，鼠标停在上面显示完整内容（题目的提示里还有作者、年份、期刊和全部标签）。
- 面板宽度：拖动文献列表和详情之间的分隔线，宽度会记住；双击分隔线恢复默认。`Ctrl` / `⌘` + `E` 一键把详情加宽、再按回来。
- 阅读模式：点文献标题右边的展开图标（`Ctrl` / `⌘` + `Shift` + `F`，可改键），侧边栏和文献列表收起，整个窗口留给这篇文献，顶上只剩题目和三个标签页；同一个位置变成还原图标，再点一下或按 `Esc` 退出，旁边的 × 关闭这篇文献。不必先切到 PDF 页。进出阅读模式，PDF 停在原来读到的地方，对话和没发出的问题也都还在。
- 查找：PDF 有键盘焦点时（点一下页面）按 `Ctrl` / `⌘` + `F`，左上角出现查找栏，在整份 PDF 里找输入的词（不分大小写，跨行、连字符断开的词也找得到），找到的地方标出底色；`Enter` 或箭头逐处跳转，`Esc` 收起。在 PDF 里选中了文字时先填上它。
- 引文对不上时自己找：点引用、出处跳到 PDF 时，那句原文可能是改写、翻译过的，或被排版拆开了，没能逐字对上。这时提示旁有「自己搜索」：打开查找栏，先用句中较长的词（术语、名称）逐个去找，直到有一个在 PDF 里找到；也可以换成句中别的词、数字或术语自己找。
- 后退 / 前进：`Ctrl` / `⌘` + `[` 回到上一篇读过的文献，`Ctrl` / `⌘` + `]` 再回来，鼠标侧键也一样，像浏览器那样；回到的那篇停在离开时读到的地方。对照几篇文献时，在它们之间来回不用再翻回原处（可在「设置 › 快捷键」里改键）。
- 两篇并排对照：点 PDF 工具栏的「留在旁边」（图钉亮起），这篇就留住了；再从列表里选另一篇，两篇并排显示，占满窗口（`Esc` 回到文献库）。留住之后、选下一篇之前，页面上不会出现两份同样的文献；再点一下图钉取消。也可以在列表里右键另一篇选「放在旁边一栏对照」。最多在旁边留 3 篇。每一栏顶上只有一行：是哪一篇、第几页，点 × 关掉；各栏的这一行一样高，页面从同一条线开始。在哪一栏里点一下（或点它的题目、在列表里选它），那一栏就是当前栏：顶上多一条绿线，工具栏、快捷键、上方的题目和「信息」都跟到这一篇；各栏的位置不动，读到哪里、放大多少也都不变。只是滚动别的栏看一眼，不会换当前栏。栏窄的时候，工具栏不换行：先是工具只剩图标（名字在悬停里），再窄就收进末尾的「⋯」。并排时宽度先给文献：「提问」里窗口不够宽，先收起的是左边的列表，对话让到一篇文献的宽度，文献不会被挤到读不清；对话的宽度照样可以拖。窗口再窄，放不下的几篇收在最后一栏末尾的「+N」里，点开选一篇，它就显示出来，成为当前栏；窗口变宽它们自己回来。并排时旁边的「提问」是就这几篇一起问的：开场给的是比较类的问题（方法有什么不同、结论是否一致、列表对比），回答逐篇标出处，点出处会在那一篇自己的栏里找到原文；在哪一栏读都是同一段对话，历史里也按这几篇一起存。增减一栏，就换一段新对话。打开「译文」时，并排的每一篇都带着自己的译文：窗口够宽就是「原文 | 译文 | 原文 | 译文」，不够宽时译文一起退到各自原文的下面；旁边那篇的译文进度和「翻译全文」写在它的栏里，同一时间只翻译一篇。
- 新窗口：PDF 工具栏的「新窗口」或文献右键菜单的「在新窗口中阅读」把这篇放进一个单独的窗口去读，文献库的窗口回到列表，可以接着看别的文献的摘要、记录或提问。阅读窗口顶上是题目、页码和缩放，「文献库」把这篇在文献库的窗口里打开；在里面划的线、加的笔记和在文献库窗口里一样保存，关掉窗口时记住读到的位置。暂时还不能在阅读窗口里开「译文」。
- 版面：文献标题那一行的「版面」一次切好读法：「阅读」只看原文；「对照译文」每篇带着译文；「提问」左边列表、中间对话、右边原文；「精读」占满窗口，原文、译文并排，对话在右边。只读一篇时菜单里写着分栏比例，比如「精读」是 3·3·2；并排几篇时每篇各占一份，列表和对话让出地方。切好之后各栏的宽度照样可以拖。
- 缩放：工具栏上有缩小、当前比例、放大，旁边一个方框图标是「适应整页」：无论正在适应宽度还是手动缩放，点一下就让当前这一页上下左右整页显示，并把这一页的顶端对齐到阅读区（已在整页时再点一下，回到这一页的开头）；点比例可选「适应宽度」「适应整页」或 50% 到 400%。`Ctrl` / `⌘` 加 `+`、`-`、`0` 是放大、缩小、适应宽度（可在「设置 › 快捷键」里改；眼前没有 PDF 时，这三个键改的是界面文字的大小，见「设置」一节），`Ctrl` / `⌘` 加滚轮以指针位置为中心缩放；在触控板上双指捏合也一样，张开放大、捏拢缩小。页面比面板宽时，面板底部会出现一条横向滚动条：拖动滑块或点滑块两侧就能左右移动，也可以双指横向滑动，或按住 Shift 滚动。
- 自动适配：打开文献默认「适应宽度」。在「适应宽度」或「适应整页」下，最大化或调整窗口、展开或收起侧栏、拖动面板或对话的分隔线、进出阅读模式时，页面跟着可用的宽度变化，停在正在读的那一页、那一处。选过的适应方式会带到下一篇；为看图表手动调的百分比只属于这一篇，换一篇时回到适应方式。手动缩放后，若你读的是「适应宽度」，比例旁边会出现「适应宽度」，点一下就回去（读的是「适应整页」时，点方框图标即可）。
- 滚动条：阅读区右侧有一条和文献列表一样的滚动条，表示读到了全文的哪里、一屏是全部的多少；按住滑块上下拖动快速翻到任何位置（拖动时鼠标离开细条也照样跟着走，滑块旁边显示拖到了第几页，如「12 / 38 页」），点滑块上方或下方的空处直接跳到那里。分屏时每一半各有一条，拖哪一半就翻哪一半，工具栏的页码跟着它；「译文」那一栏的滚动条和原文一起走。新窗口和用 Wisp Study 打开的 PDF 也有。
- 跳到某一页：工具栏上的「12 / 38 页」可以点，输入页码按回车就跳到那一页（超过总页数就到最后一页）。旁边固定的栏和单独的阅读窗口里暂时只显示页码。
- 页面总览：页码左边的四格图标把整份 PDF 的每一页缩小排成一排排，一眼看到哪一页是图、哪一页是表；正在读的那一页有一圈强调色，打开时就停在它那一排。点一页就跳到那一页并回到阅读，按 `Esc` 或再点一次图标也回到原来读的地方。窗口越宽一排放得越多；单独的阅读窗口里也有。缩略图上不显示标注。
- 两页并排：工具栏「分屏」菜单里的「两页并排：旁边一栏显示下一页」在原文右边多开一栏，这一栏显示的是下一页，像摊开的书；滚动哪一栏，另一栏都跟着走，始终差一页。配合「适应整页」，一屏正好两页。它是一栏，不是一种模式，所以和别的栏可以搭配：开着「译文」时是「原文｜译文｜下一页」三栏一起滚；任何一栏左上角的标签都可以改成「显示下一页」；再加一栏「下一页」就是三页并排。再点一次菜单项，或关掉那一栏，就回到一页。页码显示的是你正在操作的那一栏；读到最后一页时，「下一页」一栏停在最后一页。暂时没有一次翻两页的按键，也没有封面单独占一页的排法。
- 分屏：工具栏的「分屏」可选「左右分屏」或「上下分屏」，同一份 PDF 分成两半显示，各自滚动、翻页：图在一页、说明在另一页时，一半停在图上，另一半去读说明。「固定」时两半大小相同，缩放和适应方式一起变（改成「自由」见下一条）；选字、标注、截图、翻译在哪一半都可以用，高亮和下划线两半都看得到。页码、左右方向键翻页和从回答跳到的引用，跟着你最后点过或滚动过的那一半。选「不分屏」收起时留下最后操作的那一半的位置。分屏只属于当前这一篇，换一篇时回到不分屏；阅读模式内外都可以用。
- 分屏的固定与自由：分屏时「分屏」旁边有一个「固定 / 自由」按钮（分屏菜单里也有这一项），选择会记住。「固定」是原来的样子：两边一样宽，缩放一起变。点成「自由」后，中间的分隔线可以左右（上下分屏时上下）拖动，一边宽一边窄，双击分隔线回到对半；点一下某一边就选中它，选中的一边顶上有一道彩色的线，工具栏的页码、缩放和 `Ctrl` / `⌘` + 滚轮只改这一边，两边各自记着自己的缩放。比如一边读正文，一边把图那一侧拉宽、单独放大，核对细节。同一份 PDF 分屏和正文与附件分屏都一样可以拖、各自缩放。改回「固定」时两边回到对半，另一边停在原来的位置，缩放跟着正在操作的那一边。
- 三栏（原文 · 译文 · 原文）：已经分屏时点「译文」，得到三栏：左边两栏是原文和它的译文，一起滚动；右边一栏还是原文，留在它原来读到的地方，单独滚动，用来停在一张图、方法或参考文献上。没分屏时先开了「译文」，在「分屏」菜单里勾上「再开一栏原文：单独滚动」也是这三栏，再点一次收起右栏。这时关掉「译文」，回到原来的两半，右栏的位置不变。分屏是「自由」时也一样：点「译文」得到这三栏（三栏一样宽、缩放一起变），关掉后回到可以拖分隔线、各自缩放的两半。三栏时图号卡片上的「固定对照」把图放到右栏（图在这篇文献的另一个文件里时除外）。三栏时「分屏」菜单里没有「译文在下面」（先收起右栏再选）。旁边并排着别的文献时没有第三栏：宽度留给各篇和它们的译文。
- 每一栏自己的标签：分成两栏或三栏时，每一栏左上角有一个小标签，写着这一栏是「原文」「译文」还是「导图」。点它出菜单：「显示原文」「显示译文」「显示导图」换这一栏显示什么；「移到左边」「移到右边」（上下分屏时是「移到上面」「移到下面」）和旁边一栏换位置；「关闭这一栏」只收起这一栏。按住标签拖到旁边一栏上也是换位置。还没开译文时把某一栏设为「显示译文」，就是在这一栏开始翻译；最后一栏译文换回原文或关掉，译文也就关了。哪几栏一起滚不用设：译文跟着紧挨着它的原文（先看左边，左边不是原文再看右边），其余的原文各滚各的，所以把右边的原文拖到中间，译文就改跟它。
- 思维导图：PDF 工具栏的「导图」在旁边多开一栏，放这篇文献的思维导图，文献的题目是根，要点一层层向右展开。导图跟着文献存在文献库里，换一篇再回来还在；它和原文、译文一样是一栏，可以换位置、单独关闭，也可以和译文并排成「原文 · 译文 · 导图」。分屏时点「导图」得到「原文 · 原文 · 导图」三栏；分屏是「自由」时也一样（三栏一样宽、缩放一起变，和「译文」一样），收起导图后回到可以拖分隔线、各自缩放的两半。
  - 自己做：点一个节点选中它，`Tab` 在它下面加一个分支，`Enter` 加一个同级节点，空格或双击改字（`Enter` 保存，`Esc` 放弃），`Delete` 删除它和它下面的全部；方向键在节点间走，`Shift+Tab` 提一级，`Alt+←/→` 提一级 / 降一级，`Alt+↑/↓` 在同级里上下移；节点右边的小圆点把它下面的分支收起，收起时写着有几个。`⌘Z` / `Ctrl+Z` 撤销，加 `Shift` 重做。
  - 移动和缩放：按住空白处（或根节点）拖动整张导图，滚轮和触控板也能挪；`⌘` / `Ctrl` 加滚轮、或在触控板上双指捏合，以指针为中心放大缩小。右下角的小条显示当前比例：`−` / `+` 缩小放大，点百分比回到 100%，四角图标把整张导图放进这一栏。导图有焦点时 `⌘=` / `⌘-` / `⌘0`（Windows 上是 `Ctrl`）也是放大、缩小、放进这一栏。
  - 拖动节点：按住一个节点拖到另一个节点上，落在中间就成为它的最后一个分支，落在上缘或下缘就排到它前面或后面，松手前那里会出现强调色的圈或线；节点下面的分支跟着一起走。`Esc` 取消这次拖动，拖错了 `⌘Z` 撤销。
  - 从原文加：在 PDF 里选一段，选区旁点「加到导图」，这段话成为选中节点下面的一个节点，后面带着页码；点页码，原文那一栏跳到那一页并标出这句话。节点上的字可以改短，出处不变。
  - 让模型起草：导图栏左上角标签旁的 ✦，模型读这篇文献的全文，写出 20 到 40 个节点的大纲，画成导图；它给出处的节点，原句在文献里逐字找得到的才带页码，找不到的不带，不显示猜的页码。草稿就是你的导图，照样改。导图里已经有你自己的节点时，先问一句要不要换掉；换掉之后 `⌘Z` 还能回来。用的是「设置 › AI › 任务」里「提问」的模型，读不出全文的文献只凭摘要起草。
  - 「复制大纲」把导图复制成 Markdown 的嵌套列表，出处写在节点后面的方括号里。命令行和 MCP 的 `mind_map` 读到的也是这份大纲。
  - 已经有三栏时没有地方再开一栏：点「导图」会提示先关掉一栏，或在某一栏的标签里选「显示导图」把那一栏换成导图。原文至少留一栏：只剩一栏原文时，它不能关，也不能换成导图。
- 分屏看附件：文献有附件时，「分屏」菜单下面还列出这篇文献的每个 PDF（「另一半：正文 · …」「另一半：附件 S1 · …」），选一个附件，另一半就显示它，例如左边读正文、右边停在补充图 S2 上（窗口窄时上下排，也可以在菜单里改）。两半是两个文件，各自缩放、翻页、记位置，标注也各归各的文件。工具栏（文件名、页码、缩放、截图、方框、便签）跟着你最后点过或滚动过的那一半；文件名菜单里另一半的文件后面标着「另一半」，选它就转到那一半。点回答里引用附件或正文的出处、从图片库回到图的出处时，那个文件如果正在某一半显示，就在那一半里跳转、高亮。选「另一半」里正在读的这个文件，回到同一文件的分屏；「不分屏」只留下最后操作的那一半。打开「译文」时另一半让给译文。
- 点图号看图：正文里的图号（`Fig. 3`、`Fig. 3B`、`Figs. 2 and 4`、`Table 1`、`图 3`）可以点。鼠标移到图号上变成手形、下面出一道线；点一下，这张图连同图注就显示在图号旁边的一张卡片里，卡片上写着图号和它在第几页（文献有附件时还写明是「正文」还是「附件 S1」），太长可以在卡片里滚动。看完按 `Esc`、点 × 或点页面别处收起，页面一直停在原来读的地方。卡片下面有两个按钮：「固定对照」把这张图放到分屏的另一半，这一半接着读正文，两半各自滚动（另一半正显示附件时换成这张图；开着「译文」对照时，有第三栏才有这个按钮，图放到那一栏）；「前往原位置」让页面跳到这张图，同时左下角出现「返回刚才位置 · 第 N 页」，点它回到跳转前的那一页、那一处和当时的缩放，旁边的 × 是不回去了。图是按图注找的：图注上方画着的那一块算作这张图，表格是图注下方横线之间的那一块；图和图注不在同一页时（图注排到下一页开头，或者稿件把图注集中列出、图各占一页放在后面），卡片先显示图、再显示图注，并写明各在第几页；找不到图时只显示图注。引用 `Fig. 3B` 时显示的是整张图 3，不标出 B 在哪里。打开文件后要读完全文才知道各张图在哪里，长文件要等一两秒图号才能点。跨文件也一样：文献有 PDF 附件时，正文里的 `Supplementary Fig. S2`、`Fig. S2` 指向附件里的那张补图，卡片直接显示附件里的图和图注；在附件里读到 `Fig. 3`，显示的是正文的图 3。这时「固定对照」把那个文件放到另一半并停在这张图上，「前往原位置」把这一半换成那个文件，「返回刚才位置 · 正文 · 第 N 页」再换回来，页、位置和缩放都恢复。补充材料自己把图编成 `Figure 1`、`Figure 2` 而不带 S 的，正文里的 `Supplementary Fig. 2` 也找得到它。一个图号可能指几张图时，卡片先列出候选，每行写着图号、文件、页码和图注的开头，点一行看那张图，左上角的箭头回到候选：同一个图号在两个文件里都有（先列正在读的这个文件），或者一串连号 `Figs. 2–5` 的末尾（点 `Figs. 2` 是图 2，点 `5` 列出图 3、4、5）。附件要在后台读一遍才知道里面有哪些图，刚打开时指向附件的图号要等一会儿才能点。在单独的阅读窗口里，另一个文件的图只能预览，固定对照和前往要回到文献库窗口；开着「译文」时另一半不能换成别的文件。扫描件没有文字层，不适用。
- 从图找文字（相关文字）：反过来，在图这边，图注开头的图号（`Fig. 3 | …` 里的 `Fig. 3`）也可以点，移上去同样是手形和一道线。点一下，旁边的卡片先单独列出图注，下面是「文中提到它的 N 处」：每一处一行，写着所在部分（结果、讨论……认得出标题时才有）、文件（文献有附件时）和页码，以及从提到这张图的那一句开始的一段文字。同一段里提到几次只算一处，正文的排在前面。点一行，页面跳到那一段，提到图号的地方用黄色标出，左下角照样有「返回刚才位置」；行右边的小图标是「固定对照」，把那一段留在分屏的另一半。从正文里点图号看到的预览卡片上也有「相关文字」，左上角的箭头回到这张图。附件里的补图同样可以这样回看正文里提到它的段落，跳过去时这一半换成正文，返回时再换回附件。图片本身不能点：图的范围是估出来的，点图容易和选字、截图混在一起，所以入口放在图注的图号上。
- 选字：在页面上拖动选中文字（限于一页之内），双击选中一个完整的词（不带两侧的空格和标点，`Single-cell` 这样带连字符的算一个词），`Ctrl` / `⌘` + `C` 复制，或用选区下方的「复制」「添加到对话」。没有文字层的 PDF 选不了字。
- 标注：选中文字后点「下划线」或「高亮」（新高亮是黄色）。点一下已有的高亮，旁边出现一个小菜单：选一种颜色（黄、绿、蓝、粉、紫、红、橙，当前的那个带圈）就把这条高亮换成这个颜色，范围不变；「删除高亮」只删掉点中的这一条。两条高亮叠在一起时，点中的是后加的那条。在高亮上拖动仍是选中文字；按 Esc 或点别处收起菜单。右上角「标注」列出当前 PDF 的所有标注，可以定位原文、编辑笔记或删除。标注单独存入文献库数据库，在阅读器中按页面坐标叠加显示，缩放和重新打开后仍保留；原始 PDF 文件不变，用外部阅读器打开原文件时不会显示这些标注；要带给别人或在别的软件里看，用下面的「导出带标注的 PDF」。标注绑定具体附件，移除附件时同时移除；文献进入回收站时保留，恢复后可继续查看。内置助手、CLI 和 MCP 可通过 `list_pdf_annotations` 读取原文、笔记、类型、高亮颜色、页码和位置；用户笔记与论文原文分开提供。
- 方框：工具栏的「方框」之后，在页面上拖出一个矩形，框住一张图、图中的一块或一段文字；框是空心的，框里的内容照样看得清。可以连续画几个，再点一下「方框」或按 Esc 回到选字。像在 PPT 里选中形状一样：点一下方框的边就选中它，四角和四边中点出现控制点，下面出现菜单，可以换颜色（默认红色）或「删除方框」。拖四个角同时改宽和高，拖四边中间的控制点只拉宽或只拉高，比例随意；拖框的边移动位置（没选中时按住边直接拖也行）。缩得再小也会留一个最小尺寸，拖过对边不会翻过去或消失；拖到页面外会停在页面边缘。松手就保存，缩放、翻页、重新打开后大小和位置不变。选中时按 Delete 或 Backspace 删除，按 Esc 或点页面别处取消选中。框是空心的，框里的文字照样能选、能高亮。截图「标记」的虚线框和收藏图片时的取景框也一样用控制点改大小。图表、文字和扫描页都能用。
- 便签：工具栏的「便签」之后，点页面上任意位置（文字旁、图上、页边留白、扫描页都可以），那里出现一张便签卡片，写下想法后「保存」。便签平时收起成一个小图标，点一下展开，可以「编辑」或「删除」；按住图标拖动可以换位置。卡片尽量放在页面两侧的空白处，不挡正在读的正文。方框和便签与高亮一样按页面坐标保存，缩放、翻页、重新打开后仍在原处，也列在右上角「标注」里。
- 文本框：像 PPT 的文本框一样，把字直接写在页面上。工具栏的「文本框」之后，在页面上拖出一个框（只点一下就放一个默认大小的框），松手就能输入，中英文都行，文字在框里自动换行，回车另起一行；框跟着文字长高，不会把字藏起来。写完点页面别处或按 Esc 就保存；一个字没写就离开的框不会留下。点一下文本框选中它，出现选中边框和八个控制点：拖框里任何地方移动，拖四角同时改宽高，拖四边中点只改宽或只改高；改窄了文字重新换行、框随之变高。选中后下面的菜单里有「填充」「边框」「文字」三种颜色，各自展开一排色块：填充可以选「无」（透明）、白色和几种浅色，边框可以选「无」、黑、灰和几种彩色，文字可以选黑、灰和几种深色；新画的文本框沿用上次选的颜色。改字：选中后再点一下，或者双击，或者点菜单里的「编辑文字」；把字全删掉再离开，文本框就删掉了。删除：菜单里的「删除文本框」，或选中后按 Delete / Backspace。文字、三种颜色、大小和位置都按页面坐标保存在文献库里，缩放时框和字一起缩放、对齐原处，翻页、重新打开后仍在，也列在右上角「标注」里（显示框里的字，可在那里改字）。页面在浅色和深色主题下都是白底，所以文本框的颜色在两种主题下一样。命令行和 MCP 的 `list_pdf_annotations` 也读得到（类型 `text`，`note` 是框里的字，`style` 是三种颜色）。
- 撤销标注：在 PDF 里按 `Ctrl` / `⌘` + `Z` 撤销刚才对标注的一次改动，`Ctrl` / `⌘` + `Shift` + `Z`（Windows 上也可以 `Ctrl` + `Y`）重做。加上的下划线、高亮、方框、便签、文本框和截图标记，删掉的（撤销后原样回来：同一条标注，位置、笔记、颜色都和删之前一样），改过的笔记、文字、颜色、位置和大小，都可以撤销。每个 PDF 有自己的一串记录，撤销只改眼前这个文件；改动的地方不在视野里时页面会跳过去，让人看到它出现或消失。改一条笔记或文本框里的字算一次，保存时记下；正在输入框里打字时，`Ctrl` / `⌘` + `Z` 撤销的是输入框里的字。在单独的窗口、分屏的两半里做的标注都算在同一个文件的记录里。记录只在文献库打开期间保留，关掉文献库就清空；做了新的改动之后，之前撤销的就不能再重做。
- 导出带标注的 PDF：右上角「标注」列表底部、工具栏「⋯」菜单（工具栏放不下时）和文献详情里 PDF 文件行的右键菜单都有「导出带标注的 PDF…」，选好保存位置，就把正在看的这个文件（正文或附件）另存一份，所有标注按 PDF 标准批注写进去：高亮、下划线、方框、便签、文本框，颜色和在 Wisp Study 里一样，写的笔记是批注的内容。用其他 PDF 阅读器打开，或者发给别人，都看得到这些标注，支持批注的阅读器里还能继续编辑。原文件和库里的标注都不动；文件里原有的批注、链接保留；截图标记是给自己的，不写进去。这个文件还没有标注时只提示一句，不另存。带密码或权限保护的 PDF 不能导出（另存会去掉保护）。文本框里的中文用阅读器自带的中文字体（宋体）显示，希腊字母、箭头、数学符号和 ✓、① 这类记号用阅读器自带的标准字体显示（macOS 的预览也显示得对）；个别不带中文字体的阅读器（包括在 Wisp Study 里再打开这份导出的文件）只显示其中的英文，悬停或打开批注仍能看到全文。
- 截图：工具栏的「截图」之后，在页面上框出一块（一张图、一个表格）。框好后可以「收藏到图片库」，或者「用这张截图提问」：它会作为图片加到提问的输入框上方。
- 截图标记：框好一块后点「标记」，这一块不马上用，而是在页面上留下一圈虚线；截图状态不变，可以把一篇里要用的图和表先一口气圈完。之后点虚线框里任意一处，弹出「收藏到图片库」「用这张截图提问」和「删除标记」；收藏或提问之后标记仍在，同一块可以反复用。标记按页面坐标保存，缩放、重新打开后仍在原处，也列在右上角「标注」里（可以加一句笔记，比如打算放在哪一页幻灯片）；不在截图状态时拖它的边可以移动，点开后拖四个角改变大小。做幻灯片前先这样圈好图，再逐个收藏进图片库。
- 页面先出一张粗图，随即换成按显示大小渲染的清晰图；单页图像有上限（约 2400 万像素），在高分屏上放大到 300% 以上会略微变软。

## 图片库

从文献的 PDF 里截下来的图和表，收在左侧「收藏」里：「收藏」上面有「文献 / 图片 / 方法 / 导言」几个切换，星标的文献和收藏的图片各占一边（方法和导言见下一节）。

- 收藏：在 PDF 工具栏点「截图」，在页面上框出一张图或一个表，点「收藏到图片库」。弹出的对话框里是这张截图和四个字段：图号、图注、标签、备注。图号和图注会从这一页的文字里读出来（认 `Fig. 2 | …`、`Figure 3.`、`Table 1`、`Extended Data Fig. 4`、`图 3` 这些写法；图的图注在它下面找，表的在它上面找），收藏前看一眼、改掉不对的地方。对话框打开时 PDF 不变暗，页面回到选字状态，可以直接在页面上选中图注或正文复制，再粘到对话框里；按住对话框的标题或图片可以把它拖到一边，下次收藏时还在那个位置。收藏好的图在 PDF 上留一圈绿色虚线，左上角是对勾和图号，一眼看得出哪些图已经收过；用「标记」圈过的图收藏后，那圈虚线也变成绿色。点绿色框左上角的图号（或对勾），这张图的对话框就站到页面旁边，可以改图号、图注、标签、备注，点「移出」取消收藏；页面上它的框变成带四个角的选框，拖角改变大小、拖边移动位置，对话框里的图跟着变成新框住的那块，点「保存」后图片库里的图和位置一起更新（换下来的旧图片移到文献库文件夹下的 `removed`）。刚截下、还没收藏的那块也可以这样拖角调整。要收下一张，再点一次「截图」。
- 让模型来写：图注、标签、备注三个字段名的右边各有一个 AI 图标。点一下，提问用的模型会看着这张图写出这一项：图注（截图里看得到图号时连同图号，只填进空着的图号栏；图注在另一页、截图里没有图号时，图号要自己填）、3 到 5 个标签（优先用图片库里已有的）、两到四句解读。写出来的内容在字段里，可以改，也可以撤销；和别的字段一样，点「收藏」或「保存」才会存下来。图片会发给模型服务。
- 标签：图片有自己的标签，和文献的标签分开，适合按图的类型和用途来分（配色、UMAP、示意图……）。对话框里列出已有的标签，点一下就加上。
- 浏览：卡片上是缩略图、图号、图注、出处和标签。可以搜索图注、图号、标签、备注，以及所属文献的题目、作者、期刊和年份；点一个标签只看带它的图片。
- 回到原文：点开一张图片，「打开原文」会在右侧打开它所在的 PDF，并滚到截图的位置；「用这张图提问」把它带进这篇文献的对话；还可以复制图片、另存为文件。卡片上点右键也有这些操作。
- 文献进了回收站，它的图片暂时不显示，恢复后回来；文献从回收站彻底删除时，图片文件跟着从磁盘删除。单独移出图片库的图片不会被删除，而是移到文献库文件夹下的 `removed` 文件夹。
- 自己上传的图（在写作页的「资料库」里上传，或者拖进、粘贴进稿件）也在图片库里，卡片上写着「我上传的」和原来的文件名；它不出自任何文献。
- 图片文件在文献库文件夹的 `figures` 里，和数据库、PDF 一起备份、拷走。命令行和 MCP 的 `list_figures` 可以查询它们。

## 方法库与导言库

从文献里收藏的两种段落，也在左侧「收藏」里：「收藏」上面的切换是「文献 / 图片 / 方法 / 导言」。方法库收实验方法，用来把同类的方法放在一起比较、挑出适合自己实验的那个、调整参数时有据可查；导言库收别人的引言怎样开篇、怎样引入问题，写自己的引言时拿来对照。

- 收藏：在 PDF 上选中一段文字，选区旁边有「收藏为方法」和「收藏为导言」。弹出的对话框里，原文就是选中的文字（不需要的部分可以删去），连同所在的文献和页码一起记下；再填名称（导言写它怎样引入，例如「从临床问题切入」）、标签和备注（方法写为什么适合、改了哪些参数、依据是什么；导言写想借鉴什么）。页面右上角的「新建方法」「新建导言」可以自己记一个，它不出自任何文献。
- 浏览：每个方法或导言一行，写着名称、页码和出处、原文的开头和标签。可以搜索名称、原文、标签、备注，以及所属文献的题目、作者、期刊和年份；点一个标签只看带这个标签的。
- 方法关联图片：方法的对话框里有「关联图片」，点「添加」从图片库里挑这个方法做出来的图（例如 western blot 方法得到的那张条带图），这篇文献自己的图排在前面，也可以搜索。关联的图在方法那一行的右边显示成小图；图片的对话框里也列出关联到它的方法，点名字就打开那个方法。
- 回到原文：点开一个方法或导言，「打开原文」在右侧打开它所在的 PDF 并标出原文；「用这段提问」打开助手，在输入框里提到这一条（显示成「方法·名字」或「导言·名字」，和输入 `@` 选中它一样），接着问，例如让助手比较几种方法、说明某个参数的依据；助手会收到它的原文、你的备注、标签和出处。
- 文献进了回收站，它的方法和导言暂时不显示，恢复后回来；文献从回收站彻底删除时一起删除。移到别的文献库时跟着一起走。
- 助手可以读：命令行和 MCP 的 `list_methods`、`list_introductions` 可以查询它们，文献库里的助手问到「比较这几种方法」「别人是怎么引入的」时会先读这里。

## 全文的文字

提问、检索全文和写作页用的是从 PDF 里读出的文字。

- 读取：先按字形的位置读（保留页面上的分段），不行再换另一种读取方式。两种都读不出时，文件照样保存，但状态是「PDF 无文字」。
- 原因分开说：文件打不开、设了打开密码、两种方式都解析不了（不代表它是扫描件）、字体没有给出文字编码、页面上没有文字层。助手得到的也是同一句原因，并被要求照此转述，不去猜文件是不是扫描件或加了密。
- 在文献详情的「文件」里可以看到每个文件读出了几页文字；没读出的，下面写着原因和两个按钮：「重新读取」，以及「识别页面文字」（文字识别，OCR：读出的文字按页保存，并记下是谁读的）。用哪个引擎在「设置 › AI › 任务 › 文字识别」里选：DeepSeek OCR 把整个文件上传到 DeepSeek 识别，每个文件最多 1000 页、100 MB，按页计费，Key 与 DeepSeek 的模型共用；看图模型是「设置 › AI」里「整理全文」这项任务的模型，把页面画成图片一页一页地读，一次最多 40 页，剩下的再点一次接着读。识别过的文件有页面没读出文字时（只有图的页面、引擎漏掉的页面），文件下面有「识别没有文字的 N 页」：只把这几页再送去识别（DeepSeek OCR 也只上传、只计这几页），读出的文字放回原处，其余页面不动；还是读不出的多半是只有图的页面，会照实说。「自动」先用 DeepSeek OCR，没有 Key 时用看图模型。写作页的准备工作一行里也有同一个按钮，一次读完文献库里所有读不出文字的 PDF。
- 同一件事也是一个工具 `ocr_pdf`：`wisp ocr_pdf`、MCP 和窗口里的助手都能用（看图模型只在窗口里）；助手用之前会先问你，因为文件要上传、识别要计费。点名一个文件或一篇文献时，识别过却有页面没读出文字的，它也只把这些页再读一次。
- 在「助手」里向文献库提问时，顶部的范围说明会写出其中有几篇的 PDF 没读出文字。
- 文件一行会写出有文字的页数（「15 页中 14 页有文字」）；由查找得来的文件还会写出来源和版本。

## 查找开放全文

检索导入的文献大多只有记录，没有 PDF。「缺 PDF」视图顶部的按钮可以替这些文献找开放获取的全文，下载后附到原来的条目上，并读出文字；单篇文献在「PDF」标签里也有「查找开放全文」。

- 只找可以免费合法获取的版本：arXiv；OpenAlex 和 Europe PMC 列出的开放获取文件；以及被这两个索引标为开放获取的 Springer / BMC、Nature、Frontiers 文章在出版商那里的 PDF。不登录，不绕过付费墙，找不到就说没有。
- 查找时会把文献的 DOI 或 PMID 发给 OpenAlex、Europe PMC 和出版商；没有 DOI、PMID 或 arXiv 编号的文献查不了。
- 侧栏下方显示可点击的分段进度条：绿色为已保存，黄色为未找到地址，红色为下载失败，蓝色为正在查找，灰色为等待处理。点击打开实时详情，查看正在处理的论文、逐篇结果和失败原因；收起弹窗后继续查找，完成后仍可重新打开。
- 详情中可以停止查找：不再开始下一篇，已经发出的请求完成后仍会记入结果。保留本次总数，并显示未处理的数量。「未找到地址」仅表示本次未检索到候选 PDF 地址，不代表论文一定没有开放全文。取回来的不是 PDF（登录页、验证页）不会被存成 PDF；取回来的是论文的补充材料（开头几页只有附图、附表及其图注）也不会当作全文保存，接着试下一个地址，都不行就在失败原因里写明。
- PDF／文件夹导入和 Zotero 导入使用相同的侧栏进度条与实时详情弹窗。绿色为已导入，黄色为需要完善信息或附件，红色为导入失败，蓝色为处理中，灰色区分已跳过与等待中。PDF 导入详情会列出正在读取的文件；收起后继续导入。
- 没有取到的，打开文献的链接自己下载，再把 PDF 拖进窗口，它会按 DOI 附到原条目上。
- 同一件事也是一个工具 `find_pdf`：`wisp find_pdf`、MCP 和窗口里的助手都能用；助手用之前会先问你。

## 压缩 PDF

有些论文的 PDF 动辄上百 MB，多半是附图按原始分辨率存进去了。正文 PDF 超过 10 MB 时，文件那一行有「压缩」按钮；任何 PDF 都可以在右键菜单里选「压缩 PDF」。

- 只改图片：长边超过 2400 像素（约合 A4 页面上 200 dpi）的图片缩到 2400 像素，照片存为 JPEG，线条图、图表和截图保持无损。文字、字体、页面、链接都不变，你画的标注、读出的文字和读到的位置也都还在。压缩后会核对每一页的文字与原来一致，不一致就不保存。
- 至少小一成才替换。原文件移到文献库文件夹的 `removed/`，以后再把原文件拖进来，仍然认得是这篇文献。
- 带密码或权限保护的 PDF 不压缩。全在本机完成，不上传。
- 同一件事也是一个工具 `compress_pdf`：`wisp compress_pdf`、MCP 和窗口里的助手都能用；助手用之前会先问你。

## 建库向导

- 新建文献库后先问从哪里开始：从检索文献开始、导入已有的文献，或者先空着。
- 从检索开始：写下主题或关键词，助手为所选的数据库各拟几条取向不同的检索式，并逐条试检索；你按命中的文献选出靠谱的，保存并导入。已有的文献库也可以从「检索与导入」页进入。

## 检索与导入

- 为 PubMed、Europe PMC、Crossref、arXiv 保存检索式；「试检索」显示数据库命中总数和最新的记录，并标出哪些已在库中。
- 「运行并导入」把新文献加入文献库（都是「待判断」），已有的跳过；每次导入可以整批撤销：处理过的文献（做过收录判断、读过、收藏、写过笔记、加过标签或附件、提过问、被稿件引用）保留；没动过的移出文献库，不进回收站，所以以后的检索还能再把它们导入。移出的记录另存为文献库文件夹里的 `removed/undone-import-<批次号>.bib`，需要时可以用「导入 BibTeX / RIS」再导入。
- 一条检索式每次最多取回最新的 2000 篇（在检索式里设置，默认 50）。多于 200 篇时分几次向数据库要；中途断了，已经取回的照样导入，记录里写明在哪里中断，一小时内自动重试。第一次运行取全，之后的运行只取库里还没有的：PubMed 只下载库里没有的记录，其他数据库在一页里没有新文献、命中总数也没有多出来时就停下。
- 一次取回很多文献、几条检索式一起运行之前，在「设置 › 网络 › 文献数据库」填上联系邮箱（和 NCBI API Key）：数据库对留了联系方式的请求限得更松。不填也能检索。
- 自动更新（默认关闭）：每 6 小时、每天或每周运行已启用的检索式。应用开着时每分钟检查一次；关着时错过的，下次打开时补上；失败的最多一小时后重试。不开窗口时可以让系统的计划任务定期执行 `wisp sync_searches`（见[命令行与 MCP](CLI.md)）。

## 筛选

- 「筛选」页列出待判断的文献。助手阅读每一篇（有全文读全文，否则读摘要），给出建议、理由、一句逐字引自原文的依据和把握；引文不在原文里的不会被当作依据。
- 批量进行：几篇同时读（1 到 8 篇，在「设置 › AI」里定），页面上有进度条和正在读的文献。个别文献没判断成不会打断这一轮，连续三篇失败才停下；没判断成的留到下一轮。
- 判断完的队列按助手的建议分组（已纳入、相关、证据不足、不相关、还没有建议），可以只看其中一组。
- 建议只是建议：每一篇的收录判断由你确认，可以采纳，也可以另选；看过一组之后，也可以把整组按建议一次采纳（会先问一遍）。外部 agent 通过 MCP 或命令行只能提建议。
- 在「确认」里一起过目时，助手什么都没读到的文献（没有摘要，也没有全文）默认不勾选，留在待判断：这种「证据不足」只说明没有东西可读，不是判断的依据。要写入就自己勾上，或给它另选一个结论。
- 「确认」里点一行或用方向键移动，列表下方显示这一篇的完整建议；右上角的 × 把它收起，列表回到整页高度，勾选、改选的结论和光标都不变。收起后用 ↑↓ 移动不会让它再出现，点任意一行才重新显示；再次进入「确认」时一切从头开始。这一页的 Esc 仍是「回到队列」。
- 一轮一轮收紧：筛完之后，在「筛选目标」里写一个更严的目标，点「在已纳入的 N 篇里继续筛」，助手只读已纳入的文献；它看法不同的回到队列，在「确认」里和其他建议一起写入，每行写着「原判断」。也可以「复核已判断的 N 篇」，范围是所有判断过的文献。
- 每一轮（一个筛选目标下助手的第一次批量判断开始一轮）都记下当时的数字：筛选目标下面一行写着「第 3 轮 · 540 → 100 → 23 篇已纳入」，悬停看每一轮的日期、目标和进出数字。只靠手动判断、没让助手读过的轮次不记录。
- 队列判断完后，「把未纳入的 N 篇移到回收站…」把相关、证据不足和不相关的文献一次移进回收站（先问一遍，列出各有几篇），可以从回收站恢复。

## 提取

- 让助手替你填自定义词条：它逐篇阅读（有全文读全文，否则读摘要），为每个词条提出取值，并摘一句逐字引自原文的依据；引文不在原文里的不会被当作依据。文中没有说明的，它就答没有，不猜。
- 从三处开始：在文献列表里选中几篇，右键「让助手填写词条…」；在「自定义词条」里点「让助手填写…」，范围是当前列表；或在一篇文献详情的词条旁点 ✦，只问那一项。开始前选要问哪些词条，对话框会说要读几篇、几篇有全文。已经填好或已经问过的不会重复问，除非勾选「重新提取」。
- 词条可以带一句说明（「自定义词条」里填），告诉助手要找什么，例如“研究用的物种，写学名”。「要点」是现成的一个：一两句话概括这篇文献发现了什么，没有时对话框里可以一键添加，它就是一个普通的文本词条，也可以作为表格的一列。
- 几篇同时读（篇数和模型与筛选相同，在「设置 › AI」里定），侧栏和「提取」页上有进度，可以随时停止。个别文献没读成不会打断这一轮，连续三篇失败才停下；没有摘要也没有全文的文献不会去问。
- 一轮停下之后（连续失败、你点了停止，或个别文献没读成），进度栏上有「选模型重试」：从列出的模型里选一个，把这一轮没读成和没轮到的文献按同样的词条再读一遍。选的模型只用于这一次，不改「设置 › AI」。读的时候，进度栏左边的箭头可以把正在读的文献列表收起。
- 「提取」页列出等你确认的取值，一行是一篇文献的一个词条：取值、原文里的那句话（有页码时点击打开 PDF 并高亮这句）、出自哪篇文献。可以只看某一个词条。默认勾选的是词条还空着、且找到了原文依据的取值；词条已有别的值的、没有原文依据的不勾选，留给你判断。
- 点一行，列表下方显示这一行的全文：完整的取值、依据的原句、读的是摘要还是全文、用的模型，以及「再问一次」「对照 PDF」。右上角的 × 或 Esc（旁边开着文献时，Esc 先收起文献）把它收起，列表回到整页高度；勾选、选择和光标都不变，「写入」照常写入勾选的行。收起后用 ↑↓ 在列表里移动不会让它再出现，点任意一行才重新显示。
- 单选词条的取值只能是它的选项之一：助手的回答对不上任何选项时不会写入，那一行列出选项让你选，或者留着不写。多值词条写入时保留已有的值，新的加在后面。
- 「写入」把勾选的取值一次写进词条（要么全部写入，要么都不写），写入之后可以撤销；用不上的可以「清除」，清除的不再列出，也不会再问。写入之前什么都不会改动。
- 写入之后，这句原文留在文献详情里那个词条的下面：以后看到一个取值，可以点回它的出处。
- 外部 agent 通过 MCP 或命令行的 `suggest_field` 只能提出取值，同样出现在这里等你确认。

## 写作：导入已有的稿件，带批注审阅

- 稿件可以从零开始写，也可以从已有的文件开始：写作页「稿件」菜单里的「导入 Word / Markdown 文件…」，或者把 .docx 拖进窗口（在写作页上，.md 和 .txt 也可以）。标题变成各节；没有用标题样式的 Word 文件，按「摘要」「引言」「方法」这类常见的节名分节。
- 助手在对话里写的东西也能接着改：综述记录写好的各节，在「稿件」菜单里是「从助手的综述新建」（对话里也有「存为新稿件」）；一条回答可以「保存为新稿件」或「插入到稿件」。
- Word 文件里合作者留的批注一并读入，显示在右侧的「批注」页（和「候选句」并排的另一页）；被批注的文字在稿件里有底色，点批注上的引文回到那处文字。来自 Word 的批注只能标为已处理，不会从文件里删掉。
- 「让助手审阅这一节」（选中文字时只审阅选中的部分，可以先写一句想让它看什么）：助手像在 Word 的审阅模式里那样留批注，每条指向一处原文；需要改文字的带着「建议改为」，并优先回应合作者的批注。只有你点「采纳修改」才会改稿件：批注随之落在改后的文字上，保留原文，可以「撤回修改」。也可以「采纳全部」。再审一次会替换上一轮还没处理的批注。
- 选中文字后，段落操作在选区旁的浮动菜单里出现，分成三组：「找句子」「配引用」只在文献库里查找，不改文字；「润色」「译成…」「仿写」和你自己的命令给出改后的文字，由你决定是否替换；最后是「批注」。每个按钮悬停时说明它会给出什么。菜单随滚动定位，按 Esc 或点击外部收起。工具只在选中文字后出现：稿件底部只有一行状态，右端是这一节的字数和保存状态。选中一段时，里面的引用保持 `[1]` 或 `(Xue et al., 2025)` 的样子，不会展开成原文；要改一处引用，点它一下。「把光标所在的一段设为标题」「从光标所在的一段拆成新节」在大纲里这一节的菜单中（节名旁的箭头，或右键）。
- 「仿写」参照文献库里与这段最相近的句子改写：右边的候选句不是为这段找的时候，它先找一遍再改写；借鉴的是结构和措辞，意思以你写的为准，用到某篇文献的发现时补上 `[@Key]`。
- 在来自 Word 的稿件里，用「润色」「仿写」「译成…」替换一段、或用「配引用」加了引用之后，那一段上自动留一条助手的批注（做了什么、原文是什么）。
- 导出为 Word：来自 Word 的稿件写回原文件，没改的段落原样保留（版式、表格、图片、脚注、域代码都在原处），改过的段落只在原有的格式片段里改字；批注写成 Word 自己的批注。可以选「改动记为修订」，对方在 Word 里逐条接受或拒绝。从零写的稿件导出时同样带上批注。署名在「设置 › 通用 › 写作」。
- 导出的 Word 文件按期刊的格式写引用，文末列出参考文献（稿件里仍是 `[@Key]`）。引用是 Word 的域：点正文里的 `[1]` 或 `(Zhang et al., 2024)`（Word 里是 Ctrl / ⌘ 加点击）跳到文末对应的那一条。格式在「导出」菜单下方选：两种简单格式（作者-年份、编号），常用的期刊样式（APA、Nature、Cell、Vancouver、IEEE、GB/T 7714—2015 顺序编码和著者-出版年、Chicago 著者-年份），以及你自己添加的样式。
- 稿件里写的表格（`| … | … |` 几行连在一起，第二行是 `|---|---|`）导出到 Word 是真正的表格，不再是一行行带竖线的字：细线格子，第一行加粗、表格跨页时在每页顶上重复，各列按内容分宽度（和「预览」里一样），第二行写成 `|:--|`、`|:-:|`、`|--:|` 决定这一列靠左、居中还是靠右。格子里的加粗、斜体、删除线和代码保留，`<br>` 另起一行；格子里的引用和正文里一样按选定的格式写，点它跳到文末那一条；批注可以落在格子里的字上。来自 Word 的稿件，新写的表格插在它前面那一段之后，字体跟着周围的正文，原文件自带的表格和段落照旧不动；选了「改动记为修订」时，整张表记为插入，对方可以接受或拒绝。
- 稿件里的引用平时按导出时的格式显示：`(Xue et al., 2025)` 或 `[1]`（跟着这份稿件的引用样式，编号贯穿全稿），不再连同摘出的原句整段画出来。指针停在上面显示文献和它依据的原句；点它一下，或用方向键把光标移进去，它展开成 `[@Key p.2 "…"]` 的原文，可以改。在引用后面按一次退格是选中整条引用，再按一次才删掉。
- 「预览」把整份稿件按读者读到的样子排出来：稿件里写的表格（`| … | … |` 几行连在一起，第二行是 `|---|---|`）画成表格，各列按内容分宽度，格子里的字自动换行；引用和编辑时一样按这份稿件的引用样式显示，文末的参考文献就是导出文件里的那一份（编号格式下带编号、按引用顺序排，期刊名该斜体的斜体），正文里的 `[3]` 对得上第 3 条；库里没有的引用键保持原样，并在参考文献上方用红字指出。节里写的标题（`#`、`##`、`###`）在节名之下逐级变小，最小的也不小于正文。导出的 Markdown 里表格同样保持连在一起。
- 稿件栏头「预览」旁边的「铺满」：正文随窗口宽度铺满，窗口多宽一行就多长；再点一下回到标准宽度。设置 › 外观 的「正文宽度」里也是这一档。
- 引用样式在 设置 › 写作 里管：左边是样式列表，右边是选中那个样式的样子，一句正文里的引用和三条参考文献（多作者的、两位作者的、中文的各一条），不用导出到 Word 才知道效果。点一个样式就是默认，没有单独选过样式的稿件都用它。列表先是两种简单写法（作者-年份、编号），再按「顺序编码」和「著者-出版年」分成两组常用的期刊样式，名字用短名：Nature、Science、Cell、PNAS、The Lancet、NEJM、AMA（JAMA）、BMJ、ACS、Vancouver（NLM）、IEEE、Elsevier 和 Springer 的顺序编码与著者-出版年、PLOS、MDPI、BMC、Frontiers、APA 第 7 版、Chicago 著者-出版年，以及「GB/T 7714-2015 顺序编码」「GB/T 7714-2015 著者-出版年」。列表上方的搜索框在全部七十多个内置样式里找（例如输入 gb 还能找到 GB/T 7714-2005）；脚注式的样式稿件用不了，不列出。
- 每份稿件可以有自己的引用样式（不同稿件投不同期刊）：写作页「导出」菜单里只有三个导出动作和一行「引用样式…」，行尾写着这份稿件现在用的样式；点它打开和设置里同一张列表，选一个、看右边的样子，点「用这个样式」。第一行「跟随默认」让它重新跟着设置里的默认走。稿件里引用的显示、预览和导出的 Word 都按这份稿件的样式。以前的稿件没有单独选过，照旧跟着原来在「导出」菜单里选的那个（现在是设置里的默认）。
- 引用样式用的是 CSL，与 Zotero 相同的定义文件：从 Zotero 样式库下载的 `.csl` 用列表旁的「添加 .csl 文件…」加进来就能选，排在「自己添加的」一组；本机 Zotero 里已安装的样式也会直接列出。自己添加的样式，右边名字旁有「在访达中显示」和「移除」：移除后文件留在数据目录的 `styles/removed/` 里，提示里可以撤销。只是某个样式别名的文件（很多期刊如此）需要它所指的那个样式也在；脚注式的样式不支持。条目里的卷、期、页码取自文献记录：从 Crossref、Europe PMC、PubMed、BibTeX / RIS、Zotero 来的记录会带上，以前导入的文献这三项是空的，可以在「编辑文献」里填，或用「按题目补全」补上；空着的项样式会略过。
- 想要的格式没有现成的，可以让助手改：在对话里说清要求（例如「在 Nature 的基础上，把上标改成方括号，题目加粗」），助手读出最接近的样式、改它的 CSL、用库里的文献试排给你看，认可后存成你的样式，出现在引用样式的列表里（设置 › 写作，和写作页「导出」里的「引用样式」）由你选用。
- Word 文件的表格和图片不进稿件的文字，留在 Word 文件里；Word 里未接受的修订按接受后的文字读入。
- Markdown 文件的图片跟着稿件一起进来：文件里单独成行的 `![图注](figures/fig1.png)`（地址相对于这个 .md 文件，也可以是完整路径）会收进图片库，算作你自己上传的图，稿件里在原来的位置直接显示，图注照文件里写的；在别的工具里排好图、写好的初稿，连图带文字一步进写作页。PNG 和 JPEG 原样保存，WebP、GIF、BMP、TIFF 转成 PNG；图片库里已经有的同一张图不会再存一份。带不进来的（网上的图片、找不到的文件、SVG 和 PDF 这类格式）保留文件里原来那一行，导入后的提示里说明是哪几张、为什么，可以转成 PNG 后在「资料库」里上传。图片后面 Pandoc 的 `{width=80%}` 这类属性不保留。

## 写作：资料库和稿件里的图片

写作页大纲下面、「参考文献」上面有一行「资料库」（大纲收起时在稿件上方的工具栏里）。点开是一个对话框，里面是这篇稿件能用的图片：

- 上传自己的图：点「上传图片」选文件，也可以把图片文件拖进对话框，或者直接粘贴。支持 PNG、JPEG、WebP、GIF、BMP、TIFF；PNG 和 JPEG 原样保存，其余的转成 PNG（Word 和幻灯片只认这两种）。同一张图不会存两份。
- 找以前收藏的图：对话框里也列出图片库里的全部图片，可以按图注、标签、备注、文件名和所属文献搜索，或者只看「我上传的」「文献里收藏的」「模型生成的」「本稿已用」。资料库和「收藏」里的图片库是同一批图片，在这里上传的图也会出现在那边。
- 放进稿件：点一张图，它就放到正在写的那一节里、光标所在段落的后面，单独占一段。稿件里直接看到这张图，在版心里居中，图注在它下面；导出的 Word 里图片同样居中；还没有图注的，点图片或它下面的「在这里写图注…」就可以写。出自文献的图，图注末尾会自动带上那篇文献的引用。已经放进这份稿件的图，卡片上有「已用」。
- 更快的办法：把图片文件直接拖到稿件上，或者在稿件里粘贴一张图片，它会收进资料库并放在光标处。
- 改图注、标签、备注：鼠标移到卡片上，点右上角的笔，打开的就是图片库里那张图的对话框，关掉后回到资料库。
- 图片在稿件的文字里是一行 Markdown：`![图注](figures/….png)`，光标移到这一行时能看到并修改；删掉这一行，图就从稿件里去掉（图片仍在资料库里）。
- 导出：Word 文件里图片嵌在文件中，图在上、图注在下，太宽的缩到页面宽度；从 Word 文件导入的稿件，图片会加进原文件。Markdown 导出时，图片复制到文件旁边的 `figures` 文件夹，可以直接交给 Pandoc。「复制全文」只带图注。
- 让助手来写时，助手可以用 `list_figures` 查到这些图，并把图放进它写的段落里。

## 写作：让助手来写

写作页有两种方式，在大纲上方（大纲收起时在稿件上方）切换，同一份稿件随时可以换：

- **自己写**：你动笔。右边是候选句、批注和参考文献；助手在这里只是手边的工具：稿件底部一行按钮（找句子、配引用、润色、翻译、仿写、批注）对光标所在或选中的文字，给出的结果由你取舍。这里没有对话框，想用一句话让助手直接改稿件，换到「助手写」。
- 在写作页按 `Ctrl` / `⌘` + `F` 是在稿件里查找，不再跳去搜索文献：稿件上方出现查找栏（选中了一小段文字时先填上它），这一节里找到的地方标出底色，光标之后的第一处被选中；`Enter` 或箭头去下一处、上一处，下一处在别的节时自动翻到那一节，在「预览」里也一样会回到那一节。`Esc` 收起查找栏，光标停在找到的地方。两种方式下都可用。`Ctrl` / `⌘` + `Shift` + `F` 在写作页切换稿件的「预览」（旁边开着文献时仍是那篇文献的阅读模式）。
- **助手写**：左边仍是大纲，中间是和助手的对话，右边是稿件。交代要写什么、改什么，助手自己在文献库里找文献和原句、读全文，然后直接写进稿件：写一节的初稿、逐处修改、拟定或调整大纲、改题目和正文语言。它在对话里只说做了什么、依据哪些文献、还缺什么，正文在右边看。

助手写的时候：

- 助手每次动笔前，那一节原来的文字都留一个版本。稿件上方的「版本 2/3」左右翻看这一节的各个版本，早先的一版可以「恢复这一版」（恢复前的文字也会留一版），或「回到现在」。
- 助手改过的地方在稿件里有底色，左边缘有一条竖线；大纲里刚改过的节有一个圆点。稿件下方列出这一节的每处改动，点一下定位，可以单独「撤销」或「全部撤销」，「保留」后标记消失；换回「自己写」时这张列表还在，可以接着审。改动不在当前这一节时，右边会跟到它改的那一节。
- 稿件始终可以亲手改；选中一段文字再对助手说话，它知道你指的是这一段。
- 助手写进稿件的引用是稿件的格式 `[@Key]`；它引用时摘出的原句，在文献里确实找得到的会记为这处引用的出处（参考文献页和稿件下方可以点开核对），找不到的会被告知并要求改正。
- 助手动笔前先看文献库里的论文在同一部分（摘要、导言、方法、结果、讨论）是怎么写的，照它们的组织和说法来写；句子是它自己写的。写完后，每句话都会和它所引文献的摘要、全文比对：有一长串词一字不差的（连续八个英文词或十六个汉字以上），工具那一行会写明有几句，并告诉助手改成自己的话；加了引号的直接引语不算。你明确要原话时，它会问你是加引号还是改写。节里你已经写了的句子，没有要它改的它不动。
- 对话按稿件保存：换一份稿件就是那份稿件的对话，「历史」里是这份稿件的历次对话。
- 大纲调整时，没写过内容的节会按助手的大纲去掉，写过内容的节不会被删除。
- 这种方式下没有候选句面板，查找候选句的快捷键不起作用；需要时切回「自己写」。

在「助手」页（整个文献库的对话）里，助手同样可以改稿件，但每次都会先列出要改哪一节、改几处，等你同意。

## 朗读

- PDF 工具栏的「朗读」从当前页读起，一直读到参考文献为止；读的时候 PDF 底部有一个播放器：第几页、暂停 / 继续、播放速度（0.75× 到 2×，记住上次的选择，变速不变调）、停止。读的时候再点「朗读」也是暂停 / 继续。选中一段文字时，工具条上也有「朗读」，只读选中的部分。
- 读到哪一句，PDF 上就在那一句每一行字的下面画一道深灰的细线（字底下衬一层很淡的灰），读到下一屏时页面跟着往下走；自己翻到别处看时，页面不会被拉回去。这道线和选中文字的底色不一样，一边听一边选字也分得清哪是正在读的、哪是选中的。
- 读之前会把 PDF 的断行接回去（行尾连字符拆开的词拼回整词）。每页的页眉页脚（期刊名、作者、「Page 2 of 17」这样的页码）、[12] 这样的引用编号和网址不读。
- 第一页按题目、作者、摘要、正文的顺序读，有的期刊把题目排在摘要后面也一样；许可证和版权声明、通讯作者和邮箱、作者单位、收稿和发表日期、编辑和审稿人、关键词、期刊名和「RESEARCH」这样的栏目字样不读，作者名后面的上标编号和符号也不读。
- 小节标题单独读成一句，停一下再读下面的正文。一句话不会在缩写处断开：「et al.」「Fig.」「e.g.」「vs.」、人名缩写和植物学名后的命名人（如「(L.) Lam.」）之后，以及句点后面接小写单词时，都不算一句的结尾；标出的总是整句。
- 朗读用的是 DeepSeek 的语音服务，不是「任务」里指定的模型：需要在「设置 › AI › 模型」里添加 DeepSeek 并填写 API Key；还没配置时点「朗读」会弹出提示，一键跳到 DeepSeek 的设置（没有就替你添加好），填上 Key 就能用。声音（女声、男声）在「设置 › AI › 任务」最下面选；这里只管朗读，播客的两位主持人一女一男，各用各的声音，不受它影响。按字数计费（中文一个字算两个字符），读到哪里才请求到哪里前面一小段，中途停下不会把整篇都请求完。
- 换一篇、换一个文件或关掉 PDF，朗读就停。

## 播客

- PDF 工具栏的「播客」把这篇论文做成一档两人对谈：女主持「小星」和男主持「阿潮」聊研究背景、方法、主要发现、局限和意义。对话稿由「助手」用的模型根据题目、摘要和全文（到参考文献为止）来写，只讲论文里写了的内容；再用 DeepSeek 的两种声音（女声、男声）分别读出来。
- 稿子边写边读：点下后几秒就能听到开头，不必等整篇稿子写完。播放时 PDF 底部有播放器：暂停 / 继续、第几轮和正在说的那句话、进度条、播放速度、「⋯」（重新生成、保存）、播放列表和停止。进度条可以拖动：还在生成时，它的长度是已经生成的部分，可以拖到其中任何地方，右边的时长后面转着小圈；生成完就是整期的长度。
- 再点「播客」不会重新生成：正在放就暂停 / 继续；这篇已经存了播客，就从上次停下的地方接着放（往回退两秒；上次已经听完就从头放），不再请求任何服务。要重新生成，在播放器的「⋯」或 PDF 工具栏的「⋯」里选「重新生成播客…」，确认后才会重新写稿、重新朗读（会再次计费，旧的那一版仍留在附件里）。
- 离开这篇文献（关掉详情、换一篇、去别的页面）播客也接着播，同一个播放器移到窗口底部，多了题目；点题目回到这篇的 PDF。
- 全部声音生成后，播客的声音（WAV）和对话稿（Markdown）存为这篇文献的附件，名字是「播客 - 题目」（英文界面下是「Podcast - 题目」，稿子里两位主持人写作 Stella 和 Tide）。中途停下或出错，不会保存。存下后，「播客」旁和悬浮条上多一个下载按钮，可以把音频或稿子另存到任意位置。
- 已经生成的播客都在侧栏的「播客」里（有了才出现，数字是个数）：点开是播放列表，选一个直接播放存好的音频，不再请求任何服务、不再计费；听完一个接着放下一个，再点正在放的那个是暂停 / 继续。
- 和朗读一样，需要在「设置 › AI › 模型」里添加 DeepSeek 并填写 API Key；界面是英文时，两位主持人用英文对话。

## 翻译

- 文献详情的「摘要」旁有「显示译文」：题目和摘要在原位置换成译文。打开以后，之后点开的每一篇都会翻译，直到点「显示原文」。
- 对照译文（全文）：PDF 工具栏的「译文」把页面分成两半，一边是原文，一边是同一页、每一段换成了译文的页面，版式、图表和页码都在原处，两边一起滚动。打开前已经分屏的，译文是多出来的第三栏，见上面「三栏」。
  - 「提问」时 PDF 在对话旁边，译文照样开着；PDF 那一栏窄的时候原文和译文上下排。
  - 点「译文」就开始翻译，几段同时进行（数量在「设置 › AI › 任务」的「同时翻译的篇数」），从正在看的那一页往后译，译好一段显示一段；旁边写着已译的段数，可以「停止」。
  - 每一段译好就存进文献库：中途停下、关掉，下次点「继续翻译」只译剩下的；译过的再打开直接显示，不联网也能看。
  - 开着「译文」换一篇文献时，先只显示已有的译文，点「翻译全文」才开始。
  - 原地替换：不想把页面分成两半时，在「分屏」里选「译文替换原文」，译文就直接写在原页面上，每段在自己的位置，一栏还是一栏那么宽；并排读几篇时每篇都能整栏显示。要看原文，点一下「译文」收起，再点回来。这个选择会记住，对并排的每一篇都生效。
  - 参考文献列表、页眉页脚和图里的零散文字不翻译。分开对照时，窗口窄两半上下排，也可以在「分屏」里选右边还是下面。扫描件要先有文字层。
- 译过的文字保存在文献库里，同一段文字不会请求第二次。翻译的要求（目标语言、术语、格式）可以在「设置 › AI」里改；改了以后按新的要求重新翻译。

## 助手与提问

- 左侧的「助手」是和整个文献库的对话：可以提问，也可以交代一件事（试检索外部数据库、运行检索式导入、查找开放全文、提出筛选建议、分阶段写综述）。开始对话前，页面按「找文献、读文献、整理、写」列出它能做的事：点一句话就发出去，点一个命令则把它放进输入框，等你写上后面的内容。
- 助手可以替你整理文献：加或去标签、设星标、改阅读状态、往「我的笔记」末尾追加一段（注明是助手所记，不覆盖已有内容）。它动手之前，对话里会列出每一篇要改什么，等你同意；同意后一次写入，其中一篇有问题就一篇都不写。收录判断和自定义词条不在其中：前者它只能在筛选页提建议，后者在提取页提建议。
- 给写好的 Word 文件换引用格式：把一个 `.docx` 拖到「助手」页（或点输入框左边的「+」选它），它作为一个小标签附在问题上，然后说要什么样式，例如「改成 Nature 的格式」「用 GB/T 7714，顺序编码」「Nature 但编号用方括号」。助手先读出文件引用了什么并告诉你：文件带 Zotero / Mendeley 的引用域时，文献信息直接取自域，不用猜；否则按文字识别「参考文献」/ References 后面的条目和正文里的 [1]、[2, 4–6]、上标编号或（Zhang et al., 2024; 张三等，2020）这样的引用，条目先和文献库里的文献对（DOI、PMID、题目），对不上的按条目自己的文字读，还可以让它联网查 Crossref。确认后助手输出一个新文件，保存位置由你在对话框里选：正文里的引用就地换成新样式，每一处都是点了能跳到参考文献表对应条目的域，参考文献表整个换成新样式，其余内容、格式、图表、批注不动；也可以让它把改动写成修订。原文件不会改动，已有的文件不会被覆盖。没能识别的条目原样留在表末，引用它们的地方、带「参见」之类前缀的引用保持原样，助手会逐条说明。引用样式和写作页导出用的是同一套 CSL，改样式的办法也一样（见上）。Zotero / EndNote 的引用域重排后是普通的跳转域，之后要增删引用请在原文件里改好再重排一次。
- 把一篇文献做成幻灯片：在对话里输入 `/slides P3`（就单篇文献提问时只写 `/slides`），或者直接说「把这篇做成组会汇报的 PPT，10 页左右」。助手先读全文，再查图片库里这篇文献已收藏的图，然后写出一个 `.pptx` 文件：标题页、每页一个标题和几条要点、有图的页带图注，页脚是出处，讲稿在备注里。写之前弹出保存对话框让你选位置，关掉就是不写；已有文件不会被覆盖。幻灯片里的图只来自图片库：想让某张图出现，先在 PDF 页上「截图」把它收藏进图片库（读的时候可以先用「标记」把要用的图圈出来，之后点虚线框逐个收藏），再让助手做一次。版面是程序排的（字号按内容选，要点太多时自动接到下一页），可以在 PowerPoint、Keynote 或 WPS 里打开接着改；表格和图表不会生成，论文里的表格请按图片收藏。
- 照自己的幻灯片做：把一份 `.pptx`（课题组的模板、自己以前的汇报）拖到「助手」页，或点输入框左边的「+」选它，它作为一个小标签附在问题上，然后说「以这份为参考，把 P3 做成组会汇报」。助手先读这份幻灯片（每页的标题和要点、怎样分节、每页写多少），再做新的：新文件建在它的母版和版式上，背景、配色、字体、标志都和它一样，标题和要点排进它版式里的位置，页脚和页码用它版式里原有的位置；它自己的幻灯片不会带过来，原文件也不改。同一次对话里之后再做幻灯片，都沿用这份参考。首页的助手也收 `.pptx`，可以和一篇 PDF 一起拖进去。参考文件里的页如果大多是直接画在空白页上的文本框（没有用版式的标题和正文），新幻灯片只能沿用它的背景和主题，每页的排法不会和它一样，助手会说明。图片仍由程序排在正文的位置里；旧的 `.ppt` 读不了，请先另存为 `.pptx`。
- 把写好的稿件交给写作页，也可以在「助手」页说：附上 `.docx`（或给出 `.md`、`.txt` 文件的路径），说「把这个稿件添加到写作」。助手先列出会分成哪几节、带进来几条批注和几张图，等你同意；导入后和在写作页「导入」的一样（原文件不动，同一个文件不会导入两份），写作页原来空着的「未命名稿件」让位给它。也可以只给一个文件夹的路径（例如别的工具写稿、出图的项目文件夹）：里面或它的下一层只有一个 .docx / .md 时就是它（README 不算），有几个时助手会问是哪一个；Markdown 稿件旁边的图一起收进图片库（助手这条路只收 PNG、JPEG 和 WebP）。之后可以接着让助手读它、给它留批注。
- 助手可以读你在写作页的稿件，所以能就稿件提意见，或按稿件已有的内容接着写；要它直接改稿件时，会先列出要改什么、等你同意（在写作页的「助手写」里不用逐次同意，见上）。回答下面的「插入到稿件」把这条回答加到你选的那一节末尾，选中一段时是选区旁的「所选插入稿件」；`[P3 p.5 "…"]` 这样的引用变成稿件用的 `[@Key, p. 5]`，那一节原来的内容先留一份历史版本。
- 写作页的段落操作里有「配引用」：为选中的文字（或光标所在的段落）逐句找文献库里可以引用的文献。它不改写文字，结果是一张清单：每句话下面列出找到的文献、模型认为它贴切的理由，以及这篇文献自己的一句原文（全文里的带页码，点右上角的图标在 PDF 里看这句）。模型核对后认为可以引用的已经勾好，其余相近的收在「还有 N 篇相近的」里，可以自己改选；点「插入 N 条引用」才把 `[@Key]` 加到各句句末，可以撤销。稿件用中文写、文献是英文的也能找：翻译用的模型先把每句话变成文献那种语言的检索词。没有配置模型时，列出按用词找到的相近文献，不勾选，由你判断。
- 引用带着出处：右边「参考文献」页里，每篇文献下面是引用它的那句话所依据的文献原文，附所在的部分和页码，点一下就在 PDF 里翻到那一页并高亮这句。光标停在稿件的一处引用上，稿件下方会出现一行：这是哪篇文献、这句话依据的是它的哪句原文；参考文献页同时滚到那篇文献并标出这条出处。出处在引用时记下：在候选句上点「引用」、在「配引用」里勾选插入、把助手的回答（它引的原句）插入稿件。已经写好的引用可以事后找：点参考文献列表上方带数字的星标（或光标所在引用那一行的星标），助手到每篇被引的文献里检索，再由模型核对哪一句是依据；核对后认为文献里没有依据的，会在那篇文献下面用提醒色标出，方便检查引错的地方。出处只记在文献库里，稿件的文字仍是 `[@Key]`；句子改写后仍按内容对得上，不要的出处可以点 × 去掉。
- 向文献库提问：范围是当前列表（受视图、搜索、筛选影响），模型读到每篇的记录、笔记，以及已存 PDF 中与问题相关的页面。顶部的「文献」展开这些文献的列表：提问前是当前列表，提问后带上这次对话里的编号（P1、P2…）、每篇交给模型的是完整记录还是只有题目、给了几页全文、全文是否可读。点一行在右侧打开那篇文献，对话不动，范围也不变。
- 就单篇文献提问：模型读到该文献的记录和全文。点「提问」后窗口换成提问的布局：侧栏收起，文献成为左边一条窄列表（带搜索，↑↓ 换一篇），中间是对话，右边是这篇的 PDF，边读边问。没有 PDF 的文献布局不变，右边是「添加 PDF」和「查找开放全文」。按 Esc、点「退出提问」或切回「信息」就回到完整列表；点 PDF 工具栏右端的 × 收起 PDF，之后提问只在右侧面板里进行，点「对照 PDF」再展开。窄列表与对话、对话与 PDF 之间的分隔线都可以拖动，宽度会记住，双击恢复默认。习惯左边看论文、右边提问的，点标题行右端的 ⇄ 把 PDF 换到左边，再点一次换回来；换的时候 PDF 停在原来的页和缩放，对话和还没发出的问题都在，这个选择对之后的每篇文献和重启后都有效。
- 在 PDF 上选中的原文可以「添加到对话」：它带着页码出现在输入框上方，光标随即停在输入框里（已经写的保留），直接接着打字；提问时作为引文交给模型，回答引用它时可以原路跳回那一页。文献库的对话和这篇文献的对话同时可见时，可以选加到哪一个。也可以把页面上框出的一块作为图片提问。
- 材料不够时，助手会自己调用工具在整个文献库里检索全文、按页翻阅、查询记录。一轮调用收成一行（「检索全文 ×2 · 阅读全文」），点开看每次调用和结果；只读的调用并行执行。
- 助手要运行检索式导入文献、撤销导入或删除检索式时，会先停下来等你同意：允许这一次、这次对话里都允许，或者不允许。运行和删除检索式的卡片上写着它是哪个数据库的哪条检索式，运行的还写着最多取几条。
- 回答过程中可以随时停止；已经写出的部分留在对话里，可以接着问。模型服务繁忙或连接失败时自动重试两次。
- 提问可以带图片（最多 8 张）：直接粘贴截图，或点输入框左边的「+」选择文件。过大的图片会先缩小，TIFF、BMP 会转成 PNG。所选的模型需要支持图片输入。
- 回答按 Markdown 排版：标题、加粗和斜体、列表、表格、引用、代码块，链接可以点开。
- 回答里的图：让助手「画一张图」（作者之间的合作关系、一个方法的步骤、研究的时间线、文献按年份的分布），它用 Mermaid 写出的图会直接画在回答里，颜色跟随浅色 / 深色主题。流程图、时序图、思维导图、时间线、饼图、状态图、类图、ER 图、甘特图等都能画。鼠标移到图上，右上角有三个按钮：「原始大小」（图比栏宽时被缩小了，点它按原始大小看，可以横向滚动）、「复制图片」（白底的 PNG，可以直接贴进幻灯片或稿件）、「看源码」（看和复制 Mermaid 源码，再点一下回到图）。图画不出来时显示源码和原因。图是本地画的，不联网，也不需要浏览器。
- 助手引的原句会和文献库里保存的那一页文字逐字比对（只比字母和数字，换行和连字符不算），结果写在出处卡片上：「原文一致」、「原文在 p.N」（助手给的页码不对，这句话在第 N 页，点击会去那一页）、「只对上开头的 N%」、「原文里没有这句」、「没有全文可核对」。这只说明这句话在不在原文里；它是否足以支持论断，由你判断。`/verify` 让助手把上一个回答逐条列成「论断、原文摘录、支持到什么程度」，摘录照样经过这道比对。
- 回答里的文字可以拖动选中（跨段、表格里也可以），双击选中一个词（规则和 PDF 里一样；中文选中两侧标点之间的一串），`Ctrl` / `⌘` + `C` 复制。松开鼠标后选区旁出现一条小工具栏：「引用追问」把选中的话作为引用块放进输入框（输入框里已经写的保留），光标停在后面，接着写你的问题；「复制」同快捷键。已有稿件时、在综述的对话里，选区旁还有把所选插入稿件、记进综述的按钮。工具栏随回答滚动，靠近对话上下边时换到选区的另一侧；点别处或按 Esc 选区和工具栏一起消失。右键菜单里是同样的「引用追问」「复制」。
- 鼠标停在你的提问上，下面出现「复制」和「撤回」：撤回把这个问题和之后的对话撤下，原话和图片回到输入框（框里正在写的接在后面），改了可以再发，这也是改问题的办法；发出下一个问题之前，对话末尾的「恢复」能把撤下的放回去。回答下面除了「复制」，最后一条有「重新回答」（用同一个问题再问一次，换掉这条回答），每条都有「从这里分支」：到这条回答为止另开一个对话接着问，原对话完整留在「历史」里。撤回和重新回答只改对话，助手已经对文献库做的改动不会跟着撤销。综述的对话不能分支。
- 回答正文里的 `[P3 p.5 "…"]` 和回答下面的出处卡片都可以点击：打开这篇文献的 PDF 并跳到所引的页；助手引了原句时，这句话会在页面上高亮（那一页没有就在全文里找，找不到会明说，并可点「自己搜索」用句中的词在 PDF 里查找）。筛选建议里的原文依据同样可以点击。
- 一个回答引了很多文献时，下面先列出前 8 个出处，其余的点「另外 N 个出处」展开。
- 输入 `/` 弹出命令列表，继续输入（英文名或中文说明里的字）筛选，↑↓ 选择，Enter 或 Tab 确认：`/search 词语` 在全文和记录里检索；`/cite 一段文字` 为这段文字逐句从库里找可以引用的文献；`/review 主题` 分阶段撰写综述；`/compare P1 P3` 比较几篇文献的方法和结论；`/slides P3` 把一篇文献做成汇报用的幻灯片；`/write 部分 要写的意思` 从文献库里找这一部分的候选句来写一段；`/verify` 逐条核对上一个回答（或后面写的内容）的依据；`/compact` 把这次对话压缩成摘要；`/new` 开始新对话。
- 输入 `@` 指明说的是哪一篇：弹出的列表先是列表里选中的文献和眼前列出的文献，接着输入题目里的词、作者的姓、年份或 P3 这样的标签就在整个文献库里找，↑↓ 选择，Enter 或 Tab 确认，Esc 关闭；`a@b.com` 这样的邮箱不会弹出。选中的文献在输入框里显示成「Zhang 等 2024」，退格一下整个删掉；发出的问题里也这样显示，点它打开那篇文献。助手会收到这篇的标签、题目、作者、摘要，以及它有没有全文，可以和命令一起用，例如 `/compare @Zhang @Li`。首页的助手和还没建成文献库的对话里，`@` 还能指书架上的文献库，助手就去那个库里找。在助手（和文献库的对话）里，`@` 还能指一个标签：输入框和问题里显示成「#标签名」，助手会收到这个标签下有几篇、前 10 篇是哪些，以及怎样列出其余的；点问题里的「#标签名」就在文献列表里只看这个标签。指稿件的一节：助手写里是正在写的这份稿件的各节（排在文献前面），助手里是写作当前打开的那份；显示成「§节名」，助手会收到这一节的名称、类型、字数，短的连同正文，长的告诉它怎样读；点它就到写作里的这一节。指方法库里的一个方法或导言库里的一段导言：助手和助手写里都有（助手写里排在稿件各节之后、文献之前，照着收藏的方法写方法部分、照着别人的开头写引言时用得上），右边灰字是出自哪篇文献的哪一页，接着输入名称、标签、原文或备注里的词就能找到；显示成「方法·名字」「导言·名字」，助手会收到它的原文（文献自己的话，说明只能借鉴、不能不加引号照抄）、你的备注和标签、出处的引用写法，方法还有你给它关联的图；点它打开这一条。不选类别：`@` 之后是一张列表，文献、标签、稿件、方法、导言各在一行小标题下，接着输入就在所有类别里一起找。第一个问题发出之后，把「文献」面板里的一篇拖进对话，或点它右边的 +，就在问题里光标处提到它（第一个问题之前拖进来仍是限定只读这几篇）。在文献的「提问」里（PDF 旁边、悬浮的对话、几篇并排时同样），`@` 还能指这篇文献的一张图或一张表（文献一类里不再列出正在问的这篇）：列表最前面是「图表」，按在文件里的先后排，右边灰字是页码（附件里的写 S1 p.2，几篇并排时前面是哪一篇）；接着输入 `fig3`、`图3`、`table 2`、`表2` 或图注里的词就能找到。选中的图在输入框和问题里显示成文献自己的写法「Fig. 3」，助手会收到这张图的页码、图注，以及从 PDF 页面上截下来的这张图（像粘贴的图片一样附在问题上，显示在问题上方）；截不出来时（比如文件已经不在）只给图注和页码，并说明没有图。图要在发送时截好，还在截时问题会稍等，截好自动发出。点问题里的「Fig. 3」，PDF 就翻到这张图并标出图注，可以「返回刚才位置」。重新回答、撤回再发都只带一张这张图。用 `@` 点名只说明问的是哪一个，不会改变这次对话的范围；点到稿件的一节也不是让助手改它，不等于同意助手改动什么。
- 常用的提问可以存成自己的命令（设置 › AI › 命令）：起一个名称，写一句说明和一段模板，例如 `/style-check` 检查空泛、重复的表达。模板里的 `{}` 换成命令后面写的内容；不写 `{}` 的模板可以单独使用。自己的命令和内置命令一起出现在列表里，标着「自定义」，选中后不会自动发送。它只是一段提示：不运行脚本，不增加工具，也不绕过确认。对话里保存着当时实际发出的内容，以后修改或删除命令，不会改变旧对话问过什么。
- 技能（设置 › 自定义 › 技能里开着的）也可以用 `/` 直接调用：`/技能名称`，后面接着写要做的事。助手按这项技能的说明来做，不用等它自己判断该不该读。技能和命令出现在同一个列表里，标着「技能」；名称里有空格的、和某个命令同名的不在列表里，仍由助手在请求符合描述时自己读。助手、文献的提问和写作里的「助手写」是同一个输入框，命令和技能在三处都能用。
- 对话太长、快要超出模型的上下文时会自动压缩：先把较早几轮里读过的全文页面等工具结果裁短；还不够，就让模型把这次提问之前的对话写成一份摘要（目的和要求、问过什么、涉及的文献、已有的结论和引用、做过的操作、没做完的事），之后模型从摘要接着答。你看到的对话一句不少，压缩的位置有一条「以上对话已压缩成摘要」的线，点开可以看摘要。也可以随时输入 `/compact` 手动压缩。压缩后模型不再逐字读到之前的原话和读过的页面，需要时它会重新查阅。模型的上下文长度按名称估计，在「设置 › AI」里模型的菜单中可以改（上下文）。
- 用 DeepSeek 的模型提问时，回答下面有一行这次提问的用量：输入多少 token（其中缓存命中多少、未命中多少）、输出多少、约合多少钱，以及账户余额。token 数和余额是 DeepSeek 返回的；费用按它公布的价格估算（高峰时段全价，其余时段半价，没有计入节假日），以账单为准。一次提问里调用了几次模型，就合在一起算；压缩对话时写摘要的那次请求没有计入。
- 支持 Claude API、OpenAI 兼容的 chat/completions 和 OpenAI 的 Responses 接口。
- 单篇提问里，每条回答下面有「存为笔记」：先给你看一遍、可以改，确认后加到这篇文献「我的笔记」的末尾，不覆盖已有内容。对话里的 `[P1 p.5 "…"]` 会去掉只在这次对话里有意义的编号，页码和摘录保留；末尾注明这是模型的回答、没有核对原文。笔记本来就随文献记录一起提供给以后的提问。
- 对话保存在文献库里。没有配置模型时也能看历史对话，只是不能接着问；点「新对话」后会提示上一段已保存。点「历史」列出向文献库（或向这篇文献）提过的问题，点开一次对话可以接着问：模型会按文献库现在的内容重新读材料，以前回答里的 `[P3]` 仍然指向原来那篇文献。历史对话可以逐条删除。
- 「历史」上方可以在「助手」（或「这篇文献」）和「全部对话」之间切换：全部对话列出这个文献库里和助手的对话、和每篇文献的对话（回收站里的文献除外），每行写着是哪篇文献的（或「助手」）；稿件的对话不在其中，在写作页自己的「历史」里；几篇文献并排读时的对话也不在其中，并排着那几篇时打开「历史」就是它们的（开关这时写「这几篇文献」）。选了全部对话，文献库开着期间再打开历史还是它。对话按最后说话的日子分在「今天」「昨天」「近 7 天」「更早」下面。点别的文献的对话，会选中那篇文献、在它的提问里接着这次对话（旁边并排着别的文献时，它们先收起：那次对话只是和这一篇的）；点助手的对话，回到「助手」页接着说。
- 历史上方的搜索框按标题、文献题目和对话里问过、答过的话找（工具查到的内容不算），几个词要都出现；Esc 先清空，再按一次关上历史。右键一次对话可以「重命名…」：起的名字之后一直保留，留空就回到用第一个问题作标题。
- `/review` 让这次对话带上一份综述记录：写作要求、初步框架和大纲由你分别确认，大纲确认后一节一节保存正文，最后记下检查。初步框架来自已有综述（它们各问什么、怎么组织、哪里没讲到），大纲再对照它、按文献库里的研究重建；没有可参照的综述可以跳过这一步。对话上方是四步的进度，该你做的那一步在对话末尾的卡片里：采用最后这条回答（点一次就是记下并确认），或者发出要下一步内容的请求；也可以只采用回答里选中的一段。「查看记录」里每一项都能直接编辑，改过的在那里重新确认。记录保存在文献库，从历史对话可以接着写；已保存的正文按顺序存为新稿件，对话里的引用转成写作页的引用。完整操作见[分阶段撰写综述](TUTORIAL.md#9-分阶段撰写综述)。
- 保存一节正文时，它的每处引用成为一条证据：论断是引用所在的句子，来源是文献和页码，摘录的原句已和文献的文字比对。来源是否支持论断由你判断（支持、部分支持、不支持、无法判断）；句子或来源的内容变了，判断收回或标为待重新判断。没有引用的句子也可以手动记下依据。

## 设置

单独的设置页（首页或文献库侧栏的「设置」，默认 `Ctrl` / `⌘` + `,`），改动即时保存。

- **通用**：数据目录；启动时回到上次的界面（上次离开的文献库、页面和文献，可关闭）；自动检查更新和自动下载更新（macOS、Windows：后台下载新版本并核对校验值，下载好了问一次是否重启更新，重启后回到原来的界面；关闭后只提示有新版本）。
- **外观**：跟随系统 / 浅色 / 深色，文献列表的行高。
- **快捷键**：命令面板、搜索、添加文献、导入 PDF、打开助手、收起侧边栏、阅读模式、PDF 缩放、后退 / 前进、按 Esc 退回所有文献库等都可以改键、移除或恢复默认。
- **用键盘调文字大小**（#236）：`Ctrl` / `⌘` 加 `+`、`-` 把界面文字调大、调小一档（11–20 px，就是「设置 › 外观」里的字号），加 `0` 回到默认的 13 px；首页、文献列表、助手、写作和设置里都可以，窗口上方提示调到了多少。有 PDF 在眼前时，这三个键照旧是缩放 PDF。助手的回答一行有多宽从「设置 › 外观」的「正文宽度」（窄 / 标准 / 宽 / 铺满，和稿件正文同一个）起算：窗口宽时这一栏自动加宽，最多到这个宽度的一倍半，文字调大时也跟着放宽；还嫌两侧留白多，选「宽」或「铺满」。
- **AI**：可以放进多个模型服务（DeepSeek 的两个模型里，较小也较便宜的 deepseek-flash 排在前面：没有单独指定模型的任务默认用排在最前、能用的那个；已经指定了模型的任务不受影响；填了 API Key 后，DeepSeek 的页面右上角显示账户余额，来自它的余额接口，点一下刷新），助手、批量筛选、翻译、整理全文各用哪一个分别指定（没指定的跟随助手的模型）；每项任务下写着它管哪些功能：助手的模型也用于单篇提问、向导拟检索式、图片库的图注和标签、写作页的改写、润色和配引用，批量筛选的模型也用于提取，翻译的模型也用于 PDF 选段和写作页的候选句检索词。三种接口：Claude API、OpenAI 兼容的 chat/completions、OpenAI 的 Responses（/responses）。每个模型有自己的思考设置：默认（不发送参数）、关闭，或低到最高五档；翻译这样的任务可以用一个关闭思考的小模型。模型服务可以单独指定代理，或者填 direct 不走代理。「任务」页在各项模型任务之后还有两张卡，是不属于哪个模型的服务。网页搜索：助手和 `wisp` 的 `web_search` 工具用它搜索互联网，查软件文档、指南、新闻这些文献库之外的信息；卡片右上角的开关管它开不开，关掉后助手不再看到这个工具。下面一个引擎一行：DeepSeek（用的是「模型」里 DeepSeek 服务的 Key，不用再填一遍；还没有这个服务或它没有 Key 时，行里有按钮带你去）、Jina 和 You.com（各有一个 Key 的输入框和「获取 API Key」的链接；Key 也可以放在环境变量 JINA_API_KEY、YDC_API_KEY，这时行里写着正在使用它；You.com 的摘要是网页里与搜索词相关的几段原文）。正在用的那个引擎标着「使用中」，默认是排在前面、有 Key 的那个；另一个有 Key 的引擎旁有「改用它」。一个 Key 都没有时不亮警告，只在开关旁写着填上一个就能用。搜索按所选服务的价格计费。文字识别：读不出文字的 PDF 用哪个引擎读出页面上的文字，同样是一个开关、一个引擎一行：DeepSeek OCR（Key 也是「模型」里 DeepSeek 服务的）或看图模型（就是上面「整理全文」的模型，行里写着它的名字），正在用的标「使用中」。添加 OpenAI 或 Gemini 时自带一个对话模型和生图模型；生图模型只用于生图，不出现在其他任务的模型菜单里。一个服务只有生图模型时，模型页会提示在那里添加对话模型。「添加模型服务」里有 OpenCode Go（OpenCode 的订阅，一个 Key 用 Kimi、GLM、DeepSeek、MiniMax、Qwen 等多家模型）：自带 kimi-k3 和 glm-5.3，Key 在 OpenCode Console 订阅 Go 后取得（右上角「获取 API Key」直达），也可以放在环境变量 OPENCODE_API_KEY；每次请求都带上它要求的会话标识 x-opencode-session（这是另填「其他 OpenAI 兼容服务」做不到的）。切换接口时地址跟着换到 OpenCode Go 对应的那个（Claude API 是 /inference/go/anthropic，另外两种是 /inference/go/openai/v1），模型和 Key 不变：MiniMax、Qwen 原生走 Claude API，其余的走 OpenAI 兼容即可。
- **自定义**：给助手添加的东西，分 MCP 和 SKILL 两页。SKILL 是技能：一个带 `SKILL.md` 的文件夹，可以导入文件夹或单个 Markdown 文件，每项一个开关。点一项技能打开它自己的一页：名称、调用方式（`/名称`）、完整的描述，下面是它的文件夹，左边是文件列表，右边是选中的文件。Markdown 文件按排好的样子显示，右上角可以切到源码，也可以复制全文；不是文字的文件只说明大小。名称右边可以在访达（资源管理器）中显示这个文件夹，或移除这项技能：移除是把文件夹移到技能文件夹的 `removed` 里，不会删除，提示里可以撤销。
- **网络**：代理和文献数据库两组。代理：填一个地址（http、https、socks4、socks5 等；只写 `127.0.0.1:7890` 这样不带协议头的，按 http 代理用），文献检索、元数据查询、检查更新和模型请求都经过它。地址下面一行写的是此刻真正在用的：正在使用哪个地址；没有填或关着时，是在用哪个环境变量（ALL_PROXY / HTTPS_PROXY / HTTP_PROXY）还是直接连接；地址写得不能用时，这一行和输入框变红，说明哪里不对，以及仍在使用的是原来那个地址。地址旁的开关可以暂时停用代理，地址留着，再打开就接着用。地址在停下打字后才生效，改到一半的地址不会被拿去用。「连接测试」按现在的设置访问一次 api.crossref.org，告诉你连上了（用时几秒）还是没连上（原因）。命令行 `wisp` 用同一个设置。文献数据库：联系邮箱和 NCBI API Key，都可以不填。邮箱随检索和元数据查询发给 PubMed（NCBI）、Crossref 和 Europe PMC，只发给这三个数据库：留了邮箱，Crossref 给的限额更高，NCBI 在请求过多时先来信而不是直接封掉；NCBI API Key（「获取 API Key」打开 NCBI 账户的设置页，也可以放在环境变量 NCBI_API_KEY，这时行里写着正在使用它）让 PubMed 每秒接受 10 次请求而不是 3 次。没填邮箱时，「检索与导入」和「从检索文献开始」上有一行提示带你去填，可以关掉不再出现；数据库要求稍后再试时，原因里也会说填上哪一项能放宽。
- **存储空间**：数据目录一共占了多少，各个文献库各占多少（按大小排，条的颜色是文献库的标识色）；点开一个文献库，看文献文件（含回收站里的文献）、数据库、图片库、稿件、已移除的附件各占多少，并可以在访达 / 资源管理器中打开它的文件夹。还没存为文献库的首页对话合在「最近对话」一行，移除的文献库（数据目录下的 removed 文件夹）和其他文件单列。每次打开这一页重新计算，也可以点「重新计算」。只看不删：要腾出空间，在文件夹里清理 removed 中不再需要的内容，或清空回收站。
- **关于**：版本、检查更新（有新版本时在这里下载更新、重启并更新）、新手引导（「开始」把上面那六步再走一遍）、项目主页（用得顺手的话，欢迎到 GitHub 点个 star；用满五天后首页左下角也会请一次，点「去点 star」或「不再提示」之后就不再出现，应用不会去查你是否点了）。
