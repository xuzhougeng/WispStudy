教程 06　·　阅读

把一篇论文听一遍：朗读与播客

通勤路上、做实验等离心的时候，眼睛腾不出来，耳朵可以。本篇把库里的一篇论文听一遍：先配好语音服务，让它从当前页一句句读下去，或者只读选中的一段；再把整篇做成两位主持人的对谈，离开这篇文献也接着播。做好的播客存成这篇的附件，以后在侧栏里点一下就能再听。

场景
听一篇红薯根尖单细胞图谱的文章，先粗知大意，回头再细读。
需要
一篇带 PDF 的文献；DeepSeek 的 API Key（声音）；一个在「设置 › AI」里配置好的助手模型（播客的稿子）。
用时
配置约 3 分钟；其余是听的时间，朗读看篇幅，一档播客有多长就听多久。

本篇

  1. 先配好声音
  2. 朗读：从这一页读到参考文献
  3. 播客：两位主持人聊这篇
  4. 离开这篇，接着听
  5. 存下的音频和稿子
  6. 侧栏的「播客」：再听一遍
  7. 回顾

1先配好声音

要听的是 2024 年 BMC Plant Biology 上的 Transcriptional landscape of sweetpotato root tip development at the single-cell level，17 页，库里存了 PDF。在列表上方的搜索框里输入 sweetpotato，点这一篇，切到「PDF」。

朗读和播客的声音不来自你在「任务」里给助手指定的模型，而是 DeepSeek 的语音服务。还没配置时点「朗读」或「播客」，弹出的不是声音，而是一个提示：

点「配置 DeepSeek」，窗口转到「设置 › AI › 模型」，左边的服务列表里已经替你添加好了 DeepSeek，地址是 https://api.deepseek.com，下面写着「缺 API Key」。到 platform.deepseek.com 申请一个 Key（右上角的「获取 API Key」就通向那里），填进「API Key」一栏，列表里的「缺 API Key」变成「2 个模型」，栏下写着「已保存在本机。」。已经添加过 DeepSeek 而只差 Key 时，提示的按钮是「去填写 API Key」，落到同一个地方。

声音在旁边的「任务」页最下面选。「朗读的声音」有「女声」和「男声」两档，说明里写着用哪个服务的 Key、按字数计费。这一档管的是「朗读」；播客的两位主持人各用一种声音，不受它影响。

注意朗读和播客都会把论文的文字发给 DeepSeek，按字数计费，中文一个字算两个字符。朗读是读到哪里才请求到哪里前面一小段，中途停下不会把整篇都请求完；播客的稿子还会把题目、摘要和全文发给助手用的模型。

2朗读：从这一页读到参考文献

详情面板窄的时候，PDF 工具栏只放得下几个图标，「朗读」「播客」收在 ⋯ 菜单里。按 ⌘ + Shift + F（Windows 上是 Ctrl + Shift + F）进入阅读模式，工具栏上就有了带喇叭的「朗读」和带耳机的「播客」。

朗读从正在看的那一页读起。本例先翻到第 2 页的引言，再点「朗读」：按钮变成绿色的「停止朗读 · 第 2 页」。正在读的那一句在页面上铺一层淡绿的底色，一句读完，底色移到下一句；读到屏幕下方时，页面自己往下走，正在读的句子留在眼前。读完一页接着下一页，一直读到参考文献之前。

再点一下「停止朗读 · 第 2 页」就停下，按钮回到「朗读」。

只读选中的一段

只想听某一段时，在页面上拖选它，选区旁的那排按钮里最后一个就是「朗读」，前面是「复制」「下划线」「高亮」「添加到对话」「翻译」。本例选的是引言里讲红薯短日照、耐旱的那一句。

点它，工具栏上的按钮变成「停止朗读」，这时不带页码；这一段读完，按钮自己回到「朗读」，不会接着往下读。

3播客：两位主持人聊这篇

朗读是照着原文一句句念，适合要听原话的时候。只想先知道这篇讲了什么，就点「播客」：助手用的模型根据题目、摘要和全文（到参考文献为止）写一份对谈稿，女主持「小星」和男主持「阿潮」聊研究背景、方法、主要发现、局限和意义，再用 DeepSeek 的两种声音分别读出来。

不用等稿子写完。点下后，按钮先转着圈写「正在写播客稿…」；模型写出第一轮就开始播，按钮变成「停止播客 · 第 N 轮」，N 是正在播的那一轮；模型接着往下写，写出一轮就读一轮。再点一下这个按钮就停下。

播客稿

小星：简单说，就是给红薯的根尖拍一张细胞级别的基因表达地图，看看里面到底有哪些细胞，它们怎么从干细胞一步步变成成熟细胞。

阿潮：对，这篇论文想回答的是，红薯根尖里有多少种细胞，它们之间怎么分化，还有跟拟南芥、玉米比起来有什么不一样。

稿子只讲论文里写了的内容：品种广薯 87、酶液里摇三小时、活细胞超过 80%、用 10x Genomics 平台测序，这些在原文的摘要和第 2 页都找得到。快结束时，阿潮还提了一句论文没有解释的细节：比对率有的地方写 75%，有的地方写超过 89%。这样的话是模型读出来的，值不值得追究，要你回原文看。听播客是为了先知道大意，要引用的数字回原文核对。

4离开这篇，接着听

播客开始后可以去做别的。本例按 Esc 退出阅读模式，再按一次关掉详情，播客没有停：窗口底部浮起一条横条，左边是耳机图标，然后是题目、播到第几轮、正在说的那句话（带着是谁在说），右边三个按钮。

点横条的文字部分，回到这篇的 PDF；右边的方块是停止，中间的列表图标是播放列表（第 6 节）。只要还在播，横条就一直在底部，播到哪一轮写到哪一轮。

5存下的音频和稿子

全部声音生成后，播客存成这篇文献的两个附件：声音是 WAV，对谈稿是 Markdown。声音是赶在正在播的那一句前面生成的，所以通常还没播到结尾，播客就已经存好了，之后照样往下播。中途停下或出错，不会保存。

存好之后，阅读模式工具栏的「播客」旁多出一个下载图标，悬浮条上也有一个。点它是一个小菜单：「保存播客音频（WAV）…」「保存播客稿子（Markdown）…」，选一个，在弹出的保存对话框里另存到任意位置，比如拷到手机上听。

回到「信息」页往下翻，在「附件 / 补充材料」里能看到这两份文件，名字是「播客 - 」加题目，和这篇的其他附件放在一起。

稿子就是读出来的那份对谈，一个标题加一轮一段，用任何文本编辑器都能打开、复制、改：

6侧栏的「播客」：再听一遍

有了第一档播客，侧栏「缺 PDF」下面就多出一项「播客」，数字是存下的个数；一档也没有时它不出现。本例又给 Orthologous marker groups reveal broad cell identity conservation across plant single-cell transcriptomes 做了一档，数字变成 2。

点「播客」，弹出播放列表：每档一行，写着题目和时长。选一行就播放存好的音频，不再请求任何服务，也不再计费；悬浮条照样出现，写着第几轮和正在说的那句话，点它同样回到那篇的 PDF。再点正在放的那一行就停，悬浮条右边的方块也能停。

本例先选了 Orthologous 那一档。它放完后，没有再点什么，悬浮条上的题目就换成了红薯那一篇，从头放起。这时再打开列表，正在放的那一行前面有一个勾：

回顾

  • 在「设置 › AI › 模型」里添加 DeepSeek 并填上 API Key，在「任务」页最下面选朗读的声音；没配置时点「朗读」会直接领你过去。
  • 「朗读」从当前页读到参考文献，正在读的句子有底色，页面跟着走；选中一段可以只读这一段。
  • 「播客」由助手的模型写稿、两位主持人对谈，边写边读；离开这篇，底部的悬浮条接着播。
  • 全部生成后，音频和稿子存为这篇的附件，可以另存；侧栏的「播客」里随时再放，不再计费。
  • 下一步：听出兴趣的那篇，回来精读，见精读一篇文献。

关于这篇教程　截图和数字来自 2026 年 11 月在 macOS 上用 v0.16.0 的一次实际操作。播客的稿子由真实的模型写成；声音换成了一个本机的测试服务，所以文中不描述声音听起来怎样，时长和文件大小以你自己的为准。模型每次写的稿子不一样，步骤是一样的。
