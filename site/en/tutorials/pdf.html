Tutorial 04 · Read

Just one PDF to read: drop it in and read

A colleague sends a PDF in the group chat. You only want to read it right away and mark a few lines. You have not decided which library it belongs in, and you may not even have a library yet. Drag it onto the home page and you are in reading mode, with your annotations and reading position remembered. After reading, decide whether to keep it and where.

Scenario
You receive a BMC Biology paper on chromatin accessibility in rice root tips. You read it first, then file it in “Plant single-cell transcriptomics”.
Needs
One PDF. No model is needed. You only need to set one up in “Settings › AI” when you want to ask questions or see a translation.
Time
About 5 minutes, not counting the reading itself.

Contents

  1. Drag the PDF onto the home page
  2. Leave reading: it lives in a conversation
  3. Keep it: make a library, or move it to an existing one
  4. Open the same file again
  5. Open from Finder or File Explorer
  6. Recap

1Drag the PDF onto the home page

Open Wisp Study and stay on the home page. In this example there is one library, “Plant single-cell transcriptomics”, with 89 papers. From Finder, drag the downloaded rice-root-atlas.pdf into the window. Anywhere will do, as long as it is the home page.

When you let go, the window goes straight into reading mode for this paper. The whole window is the PDF. At the top are the title and three tabs, “Info”, “PDF” and “Ask”. The toolbar is the same as in a library, with “Translation” and “Map” among its buttons. Right after opening, the title is the file name rice-root-atlas, and the file name is also written at the top left.

The first page of this paper has its DOI printed on it. The app looks it up in the background. In this example, within about ten seconds the title at the top of the window became Chromatin accessibility illuminates single-cell regulatory dynamics of rice root tips, and the authors, journal and year were filled in too. Only the DOI is sent in the lookup. The PDF is not uploaded. For a file whose first page has no DOI, the title stays the file name, and you can complete it later in “Info”.

From here it is reading: highlights, underlines, text boxes, screenshots, and clicking a figure number in the text to see the figure. It works as in Read one paper closely, and annotations and reading position are remembered.

2Leave reading: it lives in a conversation

Press Esc (or click the restore icon at the top right) to leave reading mode. The PDF is not floating in nowhere. It is a paper in a new conversation, named after the paper's title and saying “1 papers kept in this conversation”. The name is cut short in the header. At the top are “Papers 1”, “History”, “New chat” and “Make it a library”, and on the right are this paper's details.

No model is set up in this example, so the middle of the conversation says “No model configured”. With a model, you can ask about this paper here, or in the “Ask” tab, as described in section 4 of Read one paper closely.

Click “← Home” at the top left to go back, then click the assistant button at the bottom right of the home page. The conversation is under “Recent conversations”, with the number of papers kept and the date. Click it later to carry on reading.

3Keep it: make a library, or move it to an existing one

If you decide it is worth keeping after reading, there are two ways.

The paper opens a new direction. Click “Make it a library” in the conversation. In the dialog the name is pre-filled with the conversation's name, the topic is empty and the accent color is optional. When a model is set up, the AI icon next to the name can have the model suggest a name and a topic. After you confirm, the window turns into that library on the spot. The PDF, annotations and conversation stay where they were and become its content. It is the same dialog as in building the library after talking, see Talk first, build the library later.

It belongs to an existing research topic. That is the case here: it is about root gravitropism, and goes into “Plant single-cell transcriptomics” as background reading. On the “Info” page in the details on the right, click “Move to library…” (the paper's right-click menu has it too), choose the target library and click “Move”. The dialog says that the PDF, annotations, reading position and the conversations about it all go along, and that this conversation no longer holds it.

Click “Move”. The window opens “Plant single-cell transcriptomics” with this paper first in the list and selected. A message at the top says “Moved to “Plant single-cell transcriptomics”.”, and “All papers” goes from 89 to 90. No question had been asked in the original conversation, so it was deleted along with it (moved to the removed folder in the data folder, not erased for good), and it is gone from “Recent conversations”. A conversation in which you did ask something stays.

TipAfter the move to a library, the screening status is “Pending”, because whether to include it is decided again against this library's topic.

4Open the same file again

A few days later you see the PDF in the Downloads folder again, renamed atlas-copy.pdf. Drag it onto the home page once more, and it opens this paper's reading mode directly inside “Plant single-cell transcriptomics”. The app recognizes a file by its contents, so a new name does not matter, and the annotations and reading position are there. Only a PDF that is in no library becomes a new conversation.

TipThis holds only on the home page and only when you drag a single PDF. If you drag several PDFs at once, or a Word manuscript, the assistant's conversation page opens with the files in the input box, waiting for you to say what to do, see Talk first, build the library later. Dragging a PDF into the window inside a library imports it into that library.

5Open from Finder or File Explorer

You do not need to have Wisp Study open. In Finder or File Explorer, right-click the PDF and choose “Open With › Wisp Study”. The window comes to the front and goes into reading mode just as with a drop on the home page. It does not matter where the window was, and you do not have to go back to the home page first. If you select several PDFs at once, only the first opens, and a message at the top says the others were not opened.

TipOn Windows this entry is registered by the installer, and the portable version does not have it. Wisp Study does not set itself as the default app for PDFs, so double-clicking a PDF still uses your usual reader. This section has no screenshot: the Finder menu was not captured. In this example the step was simulated in a development build, and opening another PDF while the window was on a library's list went straight into its reading mode in the same way.

Recap

  • Drag a PDF onto the home page, or use “Open With › Wisp Study”, and you go straight into reading mode. A DOI on the first page is looked up in the background to complete the title and authors.
  • A PDF that is in no library sits in a conversation named after it, which you can find under “Recent conversations”.
  • When it is worth keeping, “Make it a library” starts a new library, or “Move to library…” puts it into an existing one. The PDF, annotations and reading position go along.
  • The app recognizes a file by its contents, so opening the same PDF again takes you back to where it lives.
  • Next: read one paper closely in a library, see Read one paper closely.
